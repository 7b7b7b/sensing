Intelligent Sensing Technology 考前提炼与模拟题

本文档根据 1(1).md 里的考前讲解转写整理。原文是口头说明，转写里有不少错字，本版只保留考试相关信息、课程主线和可操作的复习重点。

1. 考试形式与复习策略

老师的整体意思是：考试不会刻意出特别难、特别偏的题，重点是检查你是否能把整门课的主线讲清楚，是否能把不同传感器的输入、输出、识别元件、信号转换方式和应用场景对应起来。

可能题型包括：

  1. 判断题
    难度较低，考基本概念对错。常见形式是给一句关于某种检测方法、识别元件、应用场景或性能指标的说法，让你判断对错。

  2. 多选题
    每题可能一个或多个正确选项。重点不是复杂计算，而是概念归类、技术对应关系、不同方法的优缺点。

  3. 小计算或定量推理题
    难度不高，可能是二选一。重点是数量级、LOD/LOQ、Beer-Lambert Law、传感器动态响应、简单电容/灵敏度关系等。

  4. 问答题
    可能让你解释某个器件、某类传感器或某种检测流程，并举两三个应用。答题要讲清楚背景、原理、输入输出、优缺点和应用。

答题策略：

  • 先说清楚检测对象是什么，也就是 input (X)。
  • 再说清楚传感器输出是什么，也就是 signal (S)。
  • 再说明中间靠什么识别或转导：酶、抗体、核酸、光吸收、电容、电阻、磁场、压电材料等。
  • 最后说清楚如何评价：sensitivity、specificity、LOD、LOQ、accuracy、precision、response time、stability、interference 等。
  • 遇到器件题，不要只背名字，要拆成“识别元件 + transducer + signal readout + application”。

2. 课程主线提炼

2.1 传感器的总框架

整门课最核心的抽象是：

[ S=f(X) ]

(X) 是真实世界中的被测量，例如葡萄糖浓度、温度、压力、位移、磁场、光吸收、抗原浓度、核酸序列。
(S) 是传感器产生的信号，例如电流、电压、电阻、电容、荧光强度、吸光度、频率、相位或图像信号。

传感器不是直接给出“真实答案”，而是把输入转成信号。校准的目的就是建立 (S) 和 (X) 的关系，然后用测得的 (S) 反推 (X)。生物分析和医学检测的核心，就是把复杂生物过程定量化。

2.2 静态特性

常见静态特性包括：

  • accuracy：测量结果接近真值的程度。
  • precision：重复测量彼此接近的程度。
  • sensitivity：输入变化引起输出变化的程度，常对应校准曲线斜率。
  • specificity：对目标物的选择性，能否排除非目标物干扰。
  • LOD：limit of detection，最低可检出量。
  • LOQ：limit of quantification，最低可定量量。
  • SNR：signal-to-noise ratio，信号和噪声的比值。
  • linearity：输入输出是否保持线性关系。
  • drift：信号随时间漂移。
  • hysteresis：同一输入在上升和下降路径下输出不同。
  • input range：可用测量范围。
  • repeatability / reproducibility：同条件重复性和不同条件复现性。

LOD/LOQ 是生物分析里非常常见的指标。常用经验式是：

[ LOD\approx \frac{3\sigma_b}{m},\quad LOQ\approx \frac{10\sigma_b}{m} ]

(\sigma_b) 是空白噪声标准差，(m) 是校准曲线斜率。3 倍和 10 倍不是绝对自然常数，而是常用经验标准。LOD 表示信号能从噪声里被看见，LOQ 表示信号足够可靠，可以定量。

2.3 医学检测中的 sensitivity 和 specificity

医学检测里，sensitivity 和 specificity 来自混淆矩阵：

[ sensitivity=\frac{TP}{TP+FN},\quad specificity=\frac{TN}{TN+FP} ]

Sensitivity 看真正患病的人里有多少被检出，关注漏诊。
Specificity 看真正健康的人里有多少被排除，关注误诊。

注意：sensitivity / specificity 是检测方法本身的性能，不等于某个人阳性之后真的患病的概率。后者还受人群患病率影响。

2.4 动态特性

很多传感器的输出不会在输入变化后瞬间达到稳定，而是需要时间。动态特性描述这个过程。

一阶系统常用时间常数 (\tau) 描述响应速度。以水银温度计为例：

[ k=\frac{K_{ex}V_b}{A_c},\quad \tau=\frac{\rho C V_b}{UA_b} ]

球泡体积 (V_b) 越大，灵敏度 (k) 越高，但时间常数 (\tau) 也越大，响应越慢。这体现了传感器设计中的 trade-off：提高灵敏度不一定同时提高速度。

二阶系统可能出现 overshoot 和 oscillation。常见指标包括：

  • rise time (t_r)：响应从低值上升到接近目标值所需时间。
  • settling time (t_s)：进入允许误差范围并保持稳定的时间。
  • overshoot：超过稳态值的幅度。
  • attenuation：相邻峰值衰减。

2.5 Biomarker

Biomarker 不是只指血液里的某个分子。它是可测量的特征，用来指示正常生物过程、病理过程、暴露或治疗响应。

常见类型：

  • molecular biomarker：葡萄糖、蛋白、核酸、代谢物等。
  • histologic biomarker：组织形态、病理切片特征等。
  • radiographic biomarker：影像中的肿瘤大小、结构变化等。
  • physiologic biomarker：血压、心率、体温、呼吸、运动等。

判断一个检测技术时，先问它测的是哪类 biomarker，再判断需要什么识别元件和 transducer。

2.6 酶传感与小分子检测

小分子检测中，酶是很常见的识别元件。酶具有选择性，并能催化反应产生可读信号。

Michaelis-Menten 方程：

[ v_0=\frac{V_{\max}[S]}{K_M+[S]} ]

低底物浓度时，响应近似线性；高底物浓度时，酶活性位点饱和，响应趋于平台。因此酶传感器通常希望工作在线性范围内。

葡萄糖传感是典型例子。葡萄糖氧化酶 GOx 催化葡萄糖和氧气反应，生成 gluconolactone 和 (H_2O_2)。第一代葡萄糖传感器常通过 Pt 电极氧化 (H_2O_2)，测得电流，从而反推葡萄糖浓度。

核心链路：

葡萄糖浓度 (\rightarrow) 酶反应速率 (\rightarrow) (H_2O_2) 生成量 (\rightarrow) 电极电流 (\rightarrow) 浓度估计。

2.7 光学检测

不同波段对应不同物理过程：

  • UV-vis：常对应电子跃迁。
  • Fluorescence：分子吸收光后再发射光。
  • FTIR：对应分子振动，包括 stretch 和 bending。
  • X-ray：对应更高能量的电子或原子结构信息。
  • Radiofrequency：可对应核自旋等过程。

Beer-Lambert Law 是典型光学定量公式：

[ A=\log_{10}\frac{I_0}{I}=\varepsilon lc ]

它说明吸光度 (A) 与浓度 (c)、光程 (l)、摩尔吸光系数 (\varepsilon) 成正比。它适合线性范围内的吸收定量，样品浑浊、强散射、高浓度时要谨慎。

荧光检测通常比吸收更灵敏，因为背景可通过波长和几何方向分离。PCR、NGS、免疫分析、细胞成像中都大量使用荧光读出。

NIR 组织窗口的背景是：短波段受血红蛋白吸收和散射影响较大，长波段又受水吸收影响。650-950 nm 区间吸收相对较低，因此适合某些组织成像和体内检测。

2.8 气味传感与 VOC

气味检测面对的是复杂混合物。人体嗅觉系统不是靠一个受体识别一种气味，而是依靠受体阵列形成响应模式。

生物嗅觉启发人工气味传感：

  • 鼻腔和纤毛结构增加接触面积。
  • GPCR 等受体识别气味分子。
  • 细胞内第二信使放大信号。
  • 嗅球和大脑处理阵列式响应模式。

人工鼻通常也不是追求单一传感器完全特异，而是用多个交叉敏感传感单元形成 fingerprint，再用统计或机器学习分类。VOC 检测可用于疾病状态、环境监测、食品安全等场景。

2.9 抗体、ELISA、SPR、QCM-D 和 lateral flow

抗体是蛋白检测中的重要识别元件。它能特异性识别抗原，因此在生物分析中非常核心。

抗体亲和力常用：

[ K_D=\frac{[A][B]}{[AB]}=\frac{k_{off}}{k_{on}} ]

(K_D) 越小，说明亲和力越强。

常见抗体检测平台：

  • SPR：无标记、实时检测表面结合导致的折射率变化。
  • QCM-D：检测质量加载和层的黏弹性质。
  • ELISA：通过酶标抗体和显色底物实现信号放大。
  • lateral flow assay：通过毛细流动、捕获线和标记颗粒实现快速检测。

Sandwich ELISA 的核心是两个抗体夹住抗原，特异性较高，但要求抗原有两个可识别表位。Competitive ELISA 常用于小分子，因为小分子通常不能被两个抗体同时夹住。

Lateral flow assay 中，control line 证明液体流动和试剂有效；test line 反映目标是否存在。若 control line 不出现，测试无效。

2.10 Aptamer、PCR、FRET 和 NGS

Aptamer 是可折叠成特定三维结构的 DNA/RNA 序列，可以像抗体一样识别蛋白、小分子或细胞表面目标。

优点：

  • 尺寸小。
  • 可体外筛选。
  • 容易化学合成和修饰。
  • 批间差异较小。

缺点：

  • 结构受盐浓度、温度、pH、核酸酶影响。
  • 在复杂样品中稳定性和背景可能是问题。

PCR/qPCR 的定量往往依赖荧光探针。TaqMan 探针、FRET 探针等把序列识别和扩增过程转成荧光变化。NGS 中也大量依赖荧光标记来读取碱基信息。

2.11 物理传感器

物理传感器把压力、位移、应变、磁场、加速度等物理量转成电信号或光信号。

常见类型：

  • 电阻式：应变片、电位器。机械形变改变电阻。
  • 电容式：压力、触摸、液位、贴合状态。面积、距离或介电常数改变电容。
  • 压电式：机械应力与电荷/电压变化耦合，适合动态压力、振动、超声。
  • 光纤传感：压力、温度、应变等改变光强、波长或相位。
  • Hall sensor：磁场使载流子偏转，产生横向 Hall voltage，可用于磁场、位置、磁珠标记检测。
  • MEMS：用微纳加工把传感结构做小，常见 transducer 包括 capacitive、piezoelectric、thermal，也可结合 microfluidic。

2.12 医疗器械转化

医疗器械不能只看技术是否先进，还要看风险和监管路径。

FDA 分类大致逻辑：

  • Class I：低风险，一般控制。
  • Class II：中等风险，一般控制 + 特殊控制。
  • Class III：高风险，常涉及植入、维持生命或严重风险，需要更严格审批。

做医疗器械时，要尽早考虑它会落在哪一类。能设计成 Class II 而不是 Class III，可能大幅减少时间和成本。

植入式或长期接触器械还要考虑 foreign body reaction、排异、炎症、材料生物相容性和长期稳定性。

3. 判断题模拟题

判断下列说法是否正确。正确写 T，错误写 F。

  1. 传感器的输出信号 (S) 可以直接等同于真实输入 (X)，不需要校准。
  2. 传递函数 (S=f(X)) 描述的是被测量和传感器输出之间的关系。
  3. Accuracy 高表示重复测量点一定非常集中。
  4. Precision 高但 accuracy 低是可能出现的。
  5. Sensitivity 通常可以理解为校准曲线的斜率。
  6. Specificity 高表示对非目标物的响应较低。
  7. LOD 通常低于 LOQ。
  8. LOQ 表示最低可检出量，LOD 表示最低可定量量。
  9. 空白噪声越大，LOD 通常越高。
  10. 校准曲线斜率越大，在相同噪声下 LOD 越低。
  11. Sensitivity 和 specificity 不受人群患病率直接影响。
  12. 阳性预测值和患病率无关。
  13. 一阶系统的时间常数越大，响应越慢。
  14. 提高传感器灵敏度一定不会影响响应速度。
  15. 水银温度计球泡体积增大可能提高灵敏度，但也可能增加响应时间。
  16. 二阶系统可能出现 overshoot。
  17. Biomarker 一定是血液里的蛋白分子。
  18. 血压可以看作 physiologic biomarker。
  19. 肿瘤大小可以看作 radiographic biomarker。
  20. 酶传感器的选择性主要来自酶对底物的识别。
  21. Michaelis-Menten 方程说明酶反应在高底物浓度下可能饱和。
  22. 第一代葡萄糖传感器常通过 (H_2O_2) 的电极反应读出信号。
  23. Amperometric sensor 主要测电压。
  24. Potentiometric sensor 主要测电位或电压。
  25. Conductometric sensor 主要测电导或电导率。
  26. Beer-Lambert Law 中吸光度随浓度增加而增加。
  27. Beer-Lambert Law 中 (l) 是比色皿中液体高度。
  28. 荧光检测读的是样品发射光，而不是简单透过光。
  29. FTIR 主要与分子振动有关。
  30. NIR 组织窗口和血红蛋白、水的吸收有关。
  31. 气味传感通常可以用单个完全特异的传感器解决所有问题。
  32. 人工鼻常依赖传感阵列产生响应指纹。
  33. 抗体检测只要能结合就一定没有非特异背景。
  34. (K_D) 越小，通常表示抗体-抗原结合越强。
  35. Sandwich ELISA 通常需要目标抗原有两个可被识别的表位。
  36. Competitive ELISA 中信号一定总是随目标浓度增加而增加。
  37. Lateral flow assay 中 control line 缺失时测试应判为无效。
  38. Aptamer 是蛋白质抗体的一种。
  39. Aptamer 可以是可折叠的 DNA/RNA 序列。
  40. qPCR 中荧光探针可以把扩增过程转成可读信号。
  41. 应变片本质上利用机械变形导致电阻变化。
  42. 电容传感中板间距增大时电容增大。
  43. 压电传感器适合动态压力和振动测量。
  44. Hall sensor 的输出是磁场本身。
  45. MEMS 只是一种单一传感原理，不涉及加工平台。
  46. 医疗器械 Class III 通常风险高、监管更严格。
  47. 设计医疗器械时只需要考虑技术性能，不需要考虑监管分类。
  48. Foreign body reaction 对植入式器械很重要。

5. 小计算与定量推理题

题 1：Beer-Lambert Law

某样品在某波长下测得 (I_0/I=10)，光程 (l=1.0\ \mathrm{cm})，摩尔吸光系数 (\varepsilon=2.0\times10^4\ \mathrm{L\,mol^{-1}\,cm^{-1}})。求浓度。

答案：

[ A=\log_{10}(10)=1 ]

[ c=\frac{A}{\varepsilon l}=\frac{1}{2.0\times10^4\times1.0}=5.0\times10^{-5}\ \mathrm{M} ]

题 2：Beer-Lambert Law 方向判断

同一物质、同一波长、同一比色皿中，浓度从 (10\ \mu M) 增加到 (20\ \mu M)，若仍在线性范围内，吸光度如何变化？

答案：吸光度约变为原来的 2 倍。

题 3：LOD/LOQ

空白噪声标准差 (\sigma_b=0.02)，校准曲线斜率 (m=0.50\ \mathrm{A.U./nM})。估计 LOD 和 LOQ。

答案：

[ LOD\approx \frac{3\times0.02}{0.50}=0.12\ \mathrm{nM} ]

[ LOQ\approx \frac{10\times0.02}{0.50}=0.40\ \mathrm{nM} ]

题 4：LOD 改善

若空白噪声不变，校准曲线斜率提高 2 倍，LOD 如何变化？

答案：LOD 变为原来的一半。

题 5：Sensitivity / Specificity

100 名患者中，检测阳性 90 人、阴性 10 人。100 名健康者中，检测阴性 95 人、阳性 5 人。求 sensitivity 和 specificity。

答案：

[ sensitivity=\frac{90}{90+10}=90\% ]

[ specificity=\frac{95}{95+5}=95\% ]

题 6：假阴性数量

某检测 sensitivity 为 80%。若 50 个真正患病样本接受检测，预计漏检多少个？

答案：检出 (50\times80\%=40) 个，漏检 10 个。

题 7：Michaelis-Menten 半最大速率

酶反应的 (V_{\max}=100\ \mathrm{nM/s})，(K_M=20\ \mu M)。当 ([S]=K_M) 时，(v_0) 是多少？

答案：当 ([S]=K_M)，(v_0=V_{\max}/2=50\ \mathrm{nM/s})。

题 8：Michaelis-Menten 区域判断

若 (K_M=1\ \mathrm{mM})，样品 ([S]=10\ \mu M)，处于线性区还是饱和区？

答案：([S]\ll K_M)，处于低浓度近似线性区。

题 9：一阶时间常数

某温度传感器时间常数 (\tau=5\ s)。若改设计后球泡体积 (V_b) 加倍，其他参数不变，(\tau) 如何变化？

答案：(\tau\propto V_b)，变为 10 s。

题 10：温度计灵敏度

若水银温度计的 bulb volume (V_b) 加倍，毛细管截面积 (A_c) 不变，灵敏度 (k) 如何变化？

答案：(k\propto V_b/A_c)，约加倍。

题 11：电容方向判断

平行板电容传感器中，压力使板间距 (d) 减小。若面积和介电常数不变，电容如何变化？

答案：由 (C\propto 1/d)，(d) 减小，电容增大。

题 12：电容介电常数判断

液位传感器中，空气逐渐被水替代。水的介电常数高于空气，电容通常如何变化？

答案：有效介电常数增大，电容增大。

题 13：抗体亲和力

抗体 A 的 (K_D=1\ \mathrm{nM})，抗体 B 的 (K_D=100\ \mathrm{nM})。哪个亲和力更强？

答案：抗体 A。(K_D) 越小，亲和力通常越强。

题 14：Hall sensor 输入输出

Hall sensor 中电流方向固定，外加垂直磁场增强，横向 Hall voltage 通常如何变化？

答案：Hall voltage 增大。Hall voltage 与磁场强度相关。

题 15：qPCR 荧光信号

若 TaqMan 探针完整时荧光被淬灭，扩增过程中探针被水解，荧光信号如何变化？

答案：荧光信号增强，因为 fluorophore 与 quencher 分离。

6. 问答题模拟题

题 1：解释传递函数在传感器中的意义。

答题要点：传感器把真实输入 (X) 转成输出信号 (S)。传递函数 (S=f(X)) 描述输入输出关系。校准用于建立这个关系，并根据测得的 (S) 反推未知 (X)。举例：葡萄糖浓度转成电流，压力转成电容或电压。

题 2：区分 accuracy 和 precision。

答题要点：accuracy 是接近真值，precision 是重复测量彼此接近。可以 precision 高但 accuracy 低，也可以 accuracy 较好但 precision 差。

题 3：解释 LOD 和 LOQ 的区别。

答题要点：LOD 是最低可检出量，表示能从噪声中看见；LOQ 是最低可定量量，要求更高信号可靠性。LOQ 通常高于 LOD。噪声越小、灵敏度越高，LOD/LOQ 越低。

题 4：为什么 sensitivity 和 specificity 不等同于阳性预测值？

答题要点：sensitivity/specificity 是检测方法本身针对患病/健康群体的性能；阳性预测值还取决于人群患病率。低患病率人群中，即使 specificity 高，阳性结果中也可能有不少假阳性。

题 5：用水银温度计说明灵敏度和响应速度的权衡。

答题要点：球泡体积增大，温度变化导致液体膨胀更多，灵敏度增加；但热容量也增加，达到热平衡更慢，时间常数增大。因此提高灵敏度可能牺牲响应速度。

题 6：什么是 biomarker？举三类例子。

答题要点：biomarker 是可测量并指示正常过程、病理过程或治疗响应的特征。例子：血糖是 molecular biomarker；肿瘤大小是 radiographic biomarker；血压是 physiologic biomarker。

题 7：解释 Michaelis-Menten 方程对酶传感器的意义。

答题要点：低浓度时反应速率近似随底物浓度线性增加；高浓度时酶活性位点饱和，响应进入平台。传感器最好在线性范围内工作，否则高浓度难以区分。

题 8：解释第一代葡萄糖传感器的工作链路。

答题要点：GOx 催化葡萄糖和氧气反应，产生 gluconolactone 和 (H_2O_2)。(H_2O_2) 在 Pt 电极上氧化产生电子，电流与葡萄糖浓度相关。通过校准由电流反推葡萄糖。

题 9：比较 potentiometric、amperometric、conductometric。

答题要点：potentiometric 测电位或电压；amperometric 测电流；conductometric 测电导或电导率。三者都是电化学读出，但输出量不同。

题 10：解释 Beer-Lambert Law 的变量和限制。

答题要点：(A=\log_{10}(I_0/I)=\varepsilon lc)。(A) 是吸光度，(I_0) 入射光，(I) 透过光，(l) 光程，(c) 浓度，(\varepsilon) 摩尔吸光系数。限制包括高浓度、散射、浑浊、杂散光和非线性。

题 11：为什么近红外适合组织检测？

答题要点：短波段受血红蛋白吸收和散射影响较强；更长波段水吸收增强。650-950 nm 附近吸收相对较低，穿透较深，适合部分体内成像和组织检测。

题 12：解释荧光检测为什么常比吸收检测灵敏。

答题要点：吸收检测测入射光减少，背景大；荧光检测测样品发射光，可通过波长和方向区分激发光与发射光，背景较低，适合低浓度检测。但荧光有光漂白、自发荧光、淬灭等问题。

题 13：解释气味传感为什么常用阵列。

答题要点：气味是复杂混合物，单个受体或材料难以完全特异。阵列中多个传感单元对不同分子交叉响应，形成指纹图案，再用模式识别分类。

题 14：抗体为什么是蛋白检测的重要工具？

答题要点：抗体可特异识别抗原，适合蛋白等大分子检测。它可以与 SPR、QCM-D、ELISA、lateral flow 等读出方式结合。限制包括非特异吸附、交叉反应、成本和稳定性。

题 15：解释 (K_D) 的意义。

答题要点：(K_D=[A][B]/[AB]=k_{off}/k_{on})。(K_D) 越小，说明结合越强、较低浓度下也能形成较多复合物。单位是浓度。

题 16：解释 sandwich ELISA 的流程。

答题要点：孔板固定捕获抗体，样品中抗原被捕获，再加入带酶标或可被酶标二抗识别的检测抗体，最后加底物显色。目标越多，显色通常越强。优点是特异性高，限制是目标需要两个表位。

题 17：解释 lateral flow assay 中 C 线和 T 线。

答题要点：T line 显示目标被捕获；C line 证明样品流动和试剂有效。若 C line 不出现，测试无效。两条线通常表示阳性，只有 C 线表示阴性，无 C 线表示无效。

题 18：aptamer 和 antibody 有什么相似和不同？

答题要点：二者都可作为识别元件。抗体是蛋白，aptamer 是 DNA/RNA，靠折叠结构识别目标。Aptamer 可体外筛选、合成和修饰方便，但受环境和核酸酶影响。

题 19：qPCR 荧光探针为什么能定量？

答题要点：扩增过程中目标序列数量增加，荧光探针将扩增事件转成荧光信号。TaqMan 探针水解释放荧光，FRET 探针利用距离相关能量转移。实时荧光变化可反映初始模板量。

题 20：应变片如何把力学变化转成电信号？

答题要点：应变片贴在结构表面，结构受拉伸或压缩时应变片几何尺寸变化，电阻随之变化。通过电路读出电阻变化，可间接得到应变、力、压力或弯矩。

题 21：电容传感器可测哪些量？为什么？

答题要点：电容 (C\approx \varepsilon A/d)。压力可改变距离 (d)，液位可改变介电常数，触摸改变电场分布和耦合电容，材料分析可利用介电性质变化。

题 22：压电传感器为什么适合动态信号？

答题要点：压电材料在机械应力变化下产生电荷/电压，响应快，适合压力脉动、振动、超声等动态信号。静态长期压力下电荷可能泄漏，容易漂移。

题 23：光纤传感有哪些读出方式？

答题要点：可读光强变化、波长变化、相位变化。压力、温度、弯曲、应变可改变传播损耗、光栅周期、折射率或光程差。

题 24：Hall sensor 如何用于生物检测？

答题要点：Hall sensor 本身检测磁场或磁标签，不直接识别生物分子。抗体、核酸探针等负责特异识别，磁珠或磁纳米颗粒作为标签，结合事件导致局部磁场变化，被 Hall 阵列读出。

题 25：MEMS 的意义是什么？

答题要点：MEMS 是微机电系统，通过微纳加工把机械结构、传感元件、执行器和电路集成到小尺度器件中。常见 transducer 包括 capacitive、piezoelectric、thermal。优势是小型化、批量制造、集成化。

题 26：医疗器械 Class I/II/III 的区别。

答题要点：Class I 低风险，一般控制；Class II 中等风险，需要特殊控制；Class III 高风险，常涉及植入或维持生命，需要严格审批。技术开发早期就要考虑监管路径。

题 27：为什么医疗器械转化不能只看技术先进性？

答题要点：还要看风险、监管分类、临床验证、制造、成本、用户操作、稳定性、生物相容性。能否以较低风险类别进入市场会极大影响时间和成本。

题 28：foreign body reaction 为什么重要？

答题要点：植入或长期接触人体的器械会引发炎症、纤维包裹、排异或不适，影响安全性和长期稳定性。材料选择、表面修饰和器件设计都要考虑这种反应。

题 29：如果让你介绍一种传感器，答题结构怎么写？

答题要点：先说检测对象和应用场景；再说识别元件或物理效应；再说 transducer 如何把输入变成信号；再说读出方式；最后说优点、限制和例子。

题 30：为什么说这门课是一个工具箱？

答题要点：课程覆盖从分子识别到物理转导、从光学/电化学到器件转化的多个工具。实际科研和工程问题常不是发明全新原理，而是把已有识别元件、传感机制、信号放大、数据处理和工程化平台组合起来。

二者都用于……；区别在于……。A 更关注……，B 更关注……。在实际应用中，选择哪个取决于……。

模板 4：解释一个性能指标

这个指标衡量的是……；它的计算或定义是……；数值变大/变小代表……；它和另一个容易混淆的指标区别是……；在实际检测中受……影响。

8. 最后复习清单

考前至少确认自己能回答：

  • 什么是 (S=f(X))，为什么校准重要？
  • accuracy 和 precision 怎么区别？
  • sensitivity 和 specificity 的分母分别是什么？
  • LOD 和 LOQ 有什么区别？
  • 一阶响应为什么有时间常数？
  • 二阶响应为什么会 overshoot？
  • biomarker 可以有哪些类型？
  • Michaelis-Menten 的低浓度线性和高浓度饱和是什么意思？
  • 第一代葡萄糖传感器为什么是 amperometric？
  • Beer-Lambert Law 每个变量是什么意思？
  • UV-vis、fluorescence、FTIR 分别看什么？
  • NIR 组织窗口为什么存在？
  • 气味传感为什么适合阵列？
  • ELISA 和 lateral flow assay 的核心流程是什么？
  • aptamer 和 antibody 有什么区别？
  • qPCR 荧光探针怎么把扩增转成信号？
  • 应变片、电容、压电、光纤、Hall sensor 分别测什么物理变化？
  • MEMS 是什么，不是哪一种单一传感原理？
  • Class I/II/III 医疗器械为什么监管不同？
