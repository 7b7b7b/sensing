公式速查：先记“变量意义”，再记等号

传递函数\[S=f(X)\]

输入 \(X\) 是被测刺激，输出 \(S\) 是传感器信号。校准的目标是反过来由 \(S\) 估计 \(X\)。

Beer-Lambert Law\[A=\log_{10}\frac{I_0}{I}=\varepsilon l c\]

\(A\) 为吸光度，\(l\) 为光程，\(c\) 为浓度，\(\varepsilon\) 为摩尔吸光系数。

混淆矩阵\[\text{sensitivity}=\frac{TP}{TP+FN},\quad \text{specificity}=\frac{TN}{TN+FP}\]

前者看患病者中检出多少，后者看健康者中排除多少。

常用 LOD/LOQ 估计\[LOD\approx \frac{3\sigma_b}{m},\quad LOQ\approx \frac{10\sigma_b}{m}\]

\(\sigma_b\) 是空白噪声标准差，\(m\) 是校准曲线斜率。PPT 给了概念图，这里补常用计算式。

一阶温度计示例\[k=\frac{K_{ex}V_b}{A_c},\quad \tau=\frac{\rho C V_b}{UA_b}\]

大 bulb volume 提高灵敏度，但增大时间常数；接触面积可改善响应速度。

二阶响应指标\[t_r,\quad t_s,\quad \alpha,\quad \psi=\frac{\alpha-\alpha_1}{\alpha}\times 100\%\]

分别描述上升时间、稳定时间、超调和相邻峰值衰减。

Michaelis-Menten\[v_0=\frac{V_{\max}[S]}{K_M+[S]}\]

\([S]\ll K_M\) 时近似一阶；\([S]\gg K_M\) 时趋于饱和。

抗体亲和力\[K_D=\frac{[A][B]}{[AB]}=\frac{k_{off}}{k_{on}}\]

\(K_D\) 越小，结合越强；它的单位是浓度。

电容传感\[C\approx \varepsilon_0\varepsilon_r\frac{ab}{d}\]

面积和介电常数增大，电容增大；板间距增大，电容减小。

逐图精讲：把 PPT 里的图拆开看

这一节是对前面讲义的补强。PPT 是精简版，很多“真正要懂的东西”藏在图里：坐标轴、箭头、反应物、检测线、电极、梁结构和公式变量。下面按 PDF 页码把核心图裁出来逐个解释。

图 3-1：传感链路不是“传感器等于答案”

这张图是整门课最底层的框架。左边的 measurand 不是一个仪器读数，而是真实世界里你想知道的对象，例如血糖浓度、血压、位移、温度、磁场或某个蛋白的存在。它本身往往不能直接进入计算机，所以必须先表现为一个可作用在传感器上的物理或化学变量，也就是图中标成 X 的 physical measurement variable。

中间的 sensor 做的事是换能：它把 X 转成电流、电压、光强、频率、颜色、相位这类 signal variable S。右边的 display 或后端算法再把 S 转成最终的 measurement M。理解这条链路之后，后面所有例子都能套进来：酶传感里 X 是葡萄糖浓度，S 是电极电流；Beer-Lambert 里 X 是浓度，S 是吸光度；Hall 传感里 X 是磁场，S 是 Hall 电压。

这张图也提醒你，传感器输出不是天然等于真实值。真实值到显示值中间经过识别、换能、放大、滤波、校准和显示，每一步都可能带来误差、漂移、噪声或响应延迟。所以答题时不要只写一个材料或一个公式，而要说明输入是什么、换能机制是什么、输出是什么、怎样校准以及可能的干扰来自哪里。

图 3-2：Beer-Lambert Law 是一个标准传递函数

这张图用 Beer-Lambert Law 说明什么叫 transfer function。光通过样品前的强度是 I0，通过样品后的强度是 I，样品吸收越强，I 越小。把 I0 和 I 的比值取 log10，就得到吸光度 A。公式 A = log10(I0/I) = epsilon l c 说明，在固定波长、固定光程 l 的条件下，吸光度 A 与浓度 c 成正比。

从传感器角度看，浓度 c 是输入，吸光度 A 是输出，epsilon l 就是这个光学传感过程的斜率。这个斜率越大，同样的浓度变化会产生更大的吸光度变化，仪器越容易分辨。它和校准曲线里的 sensitivity 是同一个思想，只是这里的物理来源是分子吸收光。

使用这个公式时要注意条件。样品必须相对均一，不能有强散射；浓度不能高到让透射光过低；波长要选在目标物吸收明显而干扰物吸收较小的位置。如果题目让你用 Beer-Lambert Law 算浓度，先确认 I0/I 的方向没有写反，再确认光程单位是 cm，最后再讨论线性范围。

图 4-1：动态响应由暂态进入稳态

这张图讲的是传感器不是只看最终读数，还要看它追随变化的速度。横轴是时间，纵轴是输出 c(t)。当输入发生阶跃变化后，输出曲线不会立刻跳到最终稳态值，而是从初始值逐渐上升，先经历 transient state，再进入 steady state。

暂态阶段反映传感器内部的惯性、扩散、热容量、反应速度或电路滤波。比如水银温度计需要热量传入球泡，酶传感器需要底物扩散到酶层并发生反应，压力传感器的膜片也可能需要机械响应时间。稳态阶段才是最终读数接近真实输入的时候。

因此同一个传感器可能稳态很准，但动态很慢。若你用它测一个快速变化的生理信号，它可能会把峰值压低、把时间点拖后，甚至错过事件。动态特性题通常不是问最终值，而是问响应时间、上升时间、稳定时间以及是否能跟上输入变化。

图 4-2：响应可以分成暂态项和稳态项

这张小公式图把动态响应写成 c(t) = ctr(t) + css(t)。这里 css(t) 是稳态响应，代表系统最后应该到达的那部分；ctr(t) 是暂态响应，代表一开始由于初始条件、惯性或储能元件引起的额外变化。

理解这个分解可以避免把动态题当成静态题做。很多系统的暂态项会随时间衰减，例如指数衰减或振荡衰减；稳态项则决定最终平台值。你看到图 4-1 那条逐渐贴近虚线的曲线，本质上就是暂态项越来越小，稳态项越来越占主导。

如果题目问 response time 或 settling time，它问的是暂态项什么时候小到可以忽略，而不是稳态值本身是多少。实际应用中，这个问题很重要：血压脉搏、呼吸、步态和神经信号都在变化，传感器的暂态行为会直接决定你看到的波形是否真实。

图 5-1：校准曲线把物理输入变成信号输出

这张图展示校准曲线。横轴是 physical input X，也就是已知的标准输入；纵轴是 signal output Y，也就是传感器实际给出的输出。图中的圆点来自多个标准样本，直线是用这些点拟合出来的关系。

校准的意义是把抽象的传感器输出变成可解释的量。没有校准时，某个电流值或光强值只是一个仪器信号；有了校准曲线后，才能把它换算成浓度、压力、温度或位移。直线斜率代表灵敏度，截距代表背景或零点偏置，点围绕直线的分散程度反映噪声和重复性。

实际答题时要记住，校准曲线只在它覆盖的范围内可靠。未知样本如果比最高标准点还高，就不能简单把直线无限延伸；如果样本基质和标准品不同，也可能出现基质效应。严谨的传感器报告通常要说明校准范围、线性范围、R 方、LOD 和重复性。

图 5-2：精密度和准确度是两件事

靶心图用很直观的方式区分 precision 和 accuracy。accuracy 关注平均结果离真值有多近，靶心就是理想真值。precision 关注重复测量之间有多接近，也就是点群是否集中。左边的点群很集中但整体偏离靶心，说明仪器重复性好但有系统偏差；右边点群更分散，说明随机误差较大。

这个区别在传感器实验里非常常见。比如一个电化学传感器每次都稳定地比真实浓度高 10%，它的 precision 可以很好，但 accuracy 不好；通过校准可能修正这个偏差。反过来，如果平均值接近真实值，但每次测量上下乱跳，说明噪声或操作波动大，单次读数不可靠。

所以评价传感器不能只给一个漂亮的平均值，也不能只说重复测量标准差小。完整评价应同时报告偏差和离散度，并说明误差来源是系统性的还是随机性的。系统误差通常靠校准、空白扣除和对照实验修正；随机误差则要靠提高 SNR、重复测量和控制实验条件。

图 5-3：LOD 是“看得见”，LOQ 是“量得准”

这张图把噪声、LOD 和 LOQ 放在同一条信号曲线上。绿色线是 baseline，表示没有目标物时的背景水平；蓝色曲线在背景附近上下波动，这些波动就是 noise。小峰 Peak A 高过噪声一些，因此可以说目标可能存在，这对应 LOD；大峰 Peak B 高得多，足以做可靠定量，这对应 LOQ。

LOD 的含义不是最低能报出一个精确浓度，而是最低能从背景噪声中看出“有信号”。LOQ 更严格，它要求信号高到足以让定量误差可以接受。常见经验是 LOD 约为 3 倍空白噪声除以校准斜率，LOQ 约为 10 倍空白噪声除以校准斜率，但具体标准要看实验领域。

这张图还说明为什么降低噪声和提高斜率都很重要。如果基线噪声很大，真实小峰会被淹没；如果校准斜率太低，浓度变化引起的信号变化太小，也难以检出。报告低于 LOQ 的数值时最好写“检出但不可可靠定量”，而不是给出看似精确的小数。

图 5-4：灵敏度和特异性的分母不同

这张图是医学检测里最基本的四格表。列方向是真实状态：有病或无病；行方向是测试结果：阳性或阴性。真正有病且测阳性是 TP，真正无病但测阳性是 FP，真正有病却测阴性是 FN，真正无病且测阴性是 TN。

灵敏度 sensitivity 只在真正有病的人里计算，问的是这些病人有多少被检测出来，所以分母是 TP + FN。特异性 specificity 只在真正无病的人里计算，问的是这些健康人有多少被正确排除，所以分母是 TN + FP。它们不是同一个东西，也不能用同一个分母。

这张图和传感器性能直接相关。降低检测阈值通常会提高 sensitivity，因为更容易报阳性，但也可能增加 FP，降低 specificity；提高阈值则相反。因此一个诊断传感器的阈值选择其实是在假阴性和假阳性之间做权衡。筛查场景常怕漏诊，偏重 sensitivity；确诊场景常怕误诊，偏重 specificity。

图 5-5：斜率是灵敏度，平台是饱和

这张图把灵敏度、线性范围和饱和放在一起。横轴是 concentration，纵轴是 signal。曲线在低浓度时上升明显，说明输入变化能引起可测输出；到高浓度时逐渐变平，说明系统接近饱和，再增加浓度也难以产生更大信号。

斜率就是灵敏度。低浓度区斜率越大，传感器越容易分辨微小浓度变化。箭头标出的 LOL 是 limit of linearity，意思是超过这个范围后，用一条直线描述响应已经不合适。很多生物传感器因为识别位点有限、酶活性有限或电极反应有限，都会出现这种饱和行为。

这张图的实用价值在于提醒你：传感器不是越高浓度越好测。在线性区，信号和浓度之间有稳定比例关系，适合定量；在饱和区，不同浓度可能给出很接近的信号，误差会被放大。设计实验时应稀释样品或调整传感器范围，让未知样本落在线性或可靠校准区间。

图 6-1：水银温度计的灵敏度和响应速度相互牵制

这张图用水银温度计解释一阶系统中的两个关键量：灵敏度 k 和时间常数 tau。温度变化会让球泡里的水银体积膨胀，体积膨胀被细管转换成液柱高度变化。公式 k = Kex Vb / Ac 说明球泡体积 Vb 越大、细管截面积 Ac 越小，同样温度变化产生的位移越大。

但是图中第二个公式 tau = rho C Vb / (U Ab) 告诉你，球泡体积 Vb 同时也增加热容量，使温度计吸热或放热更慢，响应时间变长。U 是换热系数，Ab 是与外界接触的面积，它们越大，热交换越快，时间常数越小。

这就是工程设计里的典型权衡：提高灵敏度常常会牺牲速度。一个很大的球泡可能读数变化明显，但等它稳定需要更久；一个很小的球泡响应快，但液柱位移小、读数分辨率差。理解这张图后，遇到任何一阶传感器，都可以从“储能大小”和“交换通道大小”两个角度分析响应速度。

图 6-2：几何量决定温度计读数和动态

这张图把水银温度计的几何结构画出来，帮助理解上一张公式里的参数。球泡和细管相连，球泡所在环境温度从 Ti(t) 变化，最终趋向 Tf。液柱高度变化用 xo 表示。细管越细，同样体积膨胀造成的高度变化越大，所以灵敏度提高。

球泡与环境的接触面积和球泡体积共同决定动态响应。热量必须先穿过球泡壁进入水银，水银整体温度改变后液柱才会上升。这个过程不是瞬间完成的，因此温度计在温度突然变化时会有滞后，曲线通常近似一阶指数响应。

如果题目让你比较两个温度计，一个细管更细、球泡更大，另一个球泡更小、接触面积更大，你就不能只说哪个更好。前者可能更灵敏但更慢，后者可能响应更快但读数位移小。这种“灵敏度-时间常数”权衡是传感器设计的核心思想。

图 7-1：二阶系统用曲线读出四个时间域指标

这张图描述二阶系统对单位阶跃输入的响应。理想最终值是 1，但曲线第一次上升时超过了 1，这一段超出的高度叫 overshoot alpha。随后曲线向下再向上振荡，峰值逐渐衰减，最后进入稳态附近的误差带。

图中的 tr 是 rise time，通常定义为输出从稳态值 10% 上升到 90% 所需时间。ts 是 response time 或 settling time，表示输出进入并保持在指定误差带内的时间。右侧的 ±Delta% 误差带告诉你，稳定并不是完全等于最终值，而是误差小到工程上可以接受。

为什么传感器课要讲这张图？因为真实传感器、机械结构和读出电路都可能有惯性和弹性，快速响应时可能出现超调和振荡。一个响应很快但超调很大的压力传感器，可能会把一次脉搏峰值夸大；一个阻尼过强的系统虽然没有超调，却可能太慢。判断动态性能要同时看速度、超调和稳定性。

图 8-1：Biomarker 不只等于“血液里的分子”

这张图给出 biomarker 的宽定义：它是可测量的特征，用来指示正常生物过程、病理过程，或者机体对暴露和治疗干预的反应。它不是只指血液里的一个蛋白，也不只指基因突变。只要某个特征能被可靠测量并与生物状态有关，就可能是 biomarker。

图中把 biomarker 分成 molecular、histologic、radiographic 和 physiologic。血糖属于 molecular biomarker，因为它是一个可测分子浓度；肿瘤大小属于 radiographic biomarker，因为它可由影像测量；血压属于 physiologic biomarker，因为它反映生理功能状态。

这张图把课程后面的内容串起来。电化学血糖传感器测 molecular biomarker，血压和位移传感器测 physiologic biomarker，光学或影像方法可能测 radiographic biomarker。理解这个分类后，你就能解释为什么同一门传感课同时讲酶、抗体、核酸、压力、光纤和 MEMS。

图 9-1：酶识别不是硬钥匙模型，而是诱导契合

这张图用 induced-fit 模型解释酶为什么能作为识别元件。底物先接近酶的 active site，结合后酶的形状会发生轻微调整，使底物以更适合反应的构型被固定。随后形成 enzyme-products complex，产物离开，酶恢复并进入下一轮循环。

这和简单的“锁钥模型”相比更接近真实情况：酶不是僵硬的孔洞，而是可以在结合时发生构象变化。正是这种结构选择性和催化能力，让酶传感器能在复杂样品中优先响应特定底物，例如葡萄糖氧化酶对葡萄糖的识别。

但这也说明酶传感器会受环境影响。温度、pH、离子强度、抑制剂和底物类似物都会影响酶构象和活性。如果酶失活，传感器即使电极完好也会失去响应；如果样品中有竞争底物或抑制剂，信号也可能偏低或偏高。

图 9-2：Michaelis-Menten 解释“低浓度线性、高浓度饱和”

这张图给出 Michaelis-Menten 方程，它描述酶反应速率如何随底物浓度变化。v0 是初始反应速率，Vmax 是酶充分饱和时的最大速率，KM 是使速率达到 Vmax 一半时的底物浓度。这个方程不是单纯数学形式，而是来自酶-底物复合物形成和分解的动力学平衡。

低浓度时，底物分子少，大部分酶位点空着，增加底物会明显增加反应速率，因此响应近似线性。高浓度时，酶位点大多被占据，反应速度受酶周转能力限制，再增加底物也不能显著提高速率，于是曲线进入饱和。

这与传感器定量直接相关。酶传感器最好在低浓度线性区工作，因为电流或产物生成速率能稳定反映底物浓度。如果样品浓度太高进入饱和区，多个不同浓度会给出相似信号，必须稀释样品或采用合适的校准模型。

图 10-1：两条葡萄糖酶反应路线

这张图把两种葡萄糖相关酶反应并排列出。葡萄糖氧化酶 GOx 使用氧气作为电子受体，把葡萄糖转化为 gluconolactone，同时生成过氧化氢 H2O2。葡萄糖脱氢酶 GDH 则使用 NAD+ 等辅因子，把葡萄糖转化为 gluconolactone，同时生成 NADH。

二者都利用酶的选择性识别葡萄糖，但后续读出路线不同。GOx 路线常通过测 H2O2 的氧化电流或氧气消耗来读出葡萄糖；GDH 路线则可通过辅因子或电子介体把电子传给电极。这就是为什么同样测血糖，传感器设计可以有不同代际和不同化学体系。

这张图也能帮助你理解干扰来源。GOx 依赖氧气，因此低氧环境会影响响应；H2O2 的电氧化需要较高电位，可能受到其他可氧化分子干扰。GDH 系统减少了对氧气的依赖，但又引入辅因子、介体和酶选择性的问题。

图 10-2：第一代葡萄糖传感器的信号来自 \(H_2O_2\)

这张图展示第一代葡萄糖生物传感器的核心链路。葡萄糖先被 GOx 催化氧化，氧气参与反应，产物包括 gluconolactone 和 H2O2。图中电子最终进入电极，说明传感器真正测到的是电化学反应产生的电流，而不是葡萄糖分子本身。

第一代方案的逻辑是把葡萄糖浓度转成 H2O2 生成速率，再把 H2O2 在铂电极上的氧化转成电流。只要扩散、酶活性和电极反应条件稳定，电流就能通过校准曲线反映葡萄糖浓度。这是生物识别和电化学换能结合的典型例子。

但是图里也暗含局限。氧气既是反应物，也是体液中可能变化的物质；H2O2 氧化通常需要较高电位，这会让抗坏血酸、尿酸等干扰物也可能被氧化；酶层厚度和扩散限制还会影响响应时间。因此血糖传感器发展出介体、膜选择性和第三代直接电子转移等改进方案。

图 11-1：安培型传感器用电极反应产生电流

这张图把安培型葡萄糖传感器拆成电化学池。左边是 Ag/AgCl 参考电极和 Pt 工作电极，底部外加约 350 mV 电位。右边的膜或酶层让 glucose 和 O2 进入，反应生成 H2O2 和 gluconic acid，其中 H2O2 扩散到 Pt 电极发生氧化。

安培型传感器的关键不是“施加了电压”，而是“测量由氧化还原反应产生的电流”。参考电极提供稳定的电位基准，工作电极上发生目标电化学反应，外电路中流过的电子形成电流。这个电流大小与 H2O2 到达电极的速率相关，也就间接与葡萄糖浓度相关。

如果题目让你解释这个图，最好按三层说：酶层提供选择性，电极提供换能，外加电位决定反应能否高效发生。任何一层出问题都会影响读数，例如酶失活、膜污染、电极表面钝化、参考电极漂移或样品中干扰物氧化。

图 11-2：把总反应拆成酶反应和电极反应

这张图把葡萄糖安培传感中的反应分成多个步骤。第一步是酶反应：葡萄糖和氧气在 GOx 催化下生成葡萄糖酸和 H2O2。第二步是工作电极反应：H2O2 在铂阳极被氧化，释放电子。后面的 Ag/AgCl 和辅助电极反应维持整个电化学回路的电荷平衡。

这样拆开后就能看清因果关系。选择性主要来自 GOx，因为它决定葡萄糖是否被转化；信号强度来自 H2O2 氧化，因为这个步骤产生可测电子流；参考和辅助电极保证电位稳定和电流闭合。如果只写一个总反应，就看不出这些功能分工。

考试常会问为什么某些物质干扰安培型葡萄糖传感。答案就在这张图里：只要样品中某种物质能在类似电位下被工作电极氧化或还原，它就可能产生额外电流；如果它影响氧气浓度或酶活性，也会改变 H2O2 生成速率。

图 12-1：不同波段激发不同类型的物质响应

这张图把电磁波谱和分子响应联系起来。左边高频短波长的 gamma ray、X-ray 能量很高，能作用于核或内层电子；UV 和可见光常对应电子跃迁；红外光对应分子振动；微波和无线电波对应转动、电子自旋或核自旋等更低能量过程。

它说明光谱方法不是随便选波长，而是根据你想观察的物理过程选择能量尺度。UV-vis 适合看分子电子吸收，FTIR 适合看化学键振动，荧光需要分子吸收光后再发射光，NMR 则在射频范围利用核自旋响应。

在传感器设计中，波段选择还要考虑样品环境。比如生物组织中血红蛋白和水会强烈吸收某些波长，所以即使某个分子在某波长有响应，也不代表体内检测可行。光谱传感的核心是目标响应、背景吸收、散射和仪器读出之间的平衡。

图 12-2：比色皿里的 \(l\) 是光程，不是液体高度

这张图把 Beer-Lambert Law 的几何含义画出来。光从左边进入比色皿，穿过样品后从右边出来。图中标出的 l 是光在样品中走过的距离，也叫光程，不是比色皿里液体的高度。

为什么光程重要？因为分子吸收光的机会随路径长度增加而增加。浓度 c 越高，单位体积内吸收分子越多；光程 l 越长，光遇到这些分子的机会越多。因此吸光度同时正比于 l 和 c。

很多计算题会默认 1 cm 比色皿，但如果题目给的是 0.5 cm 或微流控通道中的短光程，就必须代入实际 l。微型传感器为了小体积牺牲光程时，吸光度可能变小，需要更灵敏的探测器或更强吸收的探针来补偿。

图 12-3：UV-vis 的核心是选波长再测透过光

这张图展示 UV-vis 仪器的基本光路。光源发出宽波段光，入口狭缝限制光束，色散元件把不同波长分开，出口狭缝选择一个窄波长，随后光穿过样品，最后由 detector 记录透过强度。

这套结构的意义是让你在指定波长下测吸收。不同分子在不同波长吸收不同，选择目标物吸收强而背景吸收弱的波长可以提高灵敏度和选择性。样品池后面的 detector 不直接知道浓度，它只知道透过光强；浓度需要通过空白、标准曲线和 Beer-Lambert Law 得到。

如果题目问 UV-vis 的局限，可以从这张图推出来。样品浑浊会散射光，导致 detector 接收到的光减少，看起来像吸收增加；单色器带宽太宽会混入其他波长；样品本身颜色或基质吸收会形成背景。因此 UV-vis 定量必须做空白校正和波长选择。

图 12-4：荧光读的是发射光，不是透过光

这张图显示同一样品的吸收、荧光和磷光峰。分子先吸收较短波长的光进入激发态，随后以较长波长发射光回到较低能级，这就是荧光。图中绿色荧光峰相对蓝色吸收峰向长波移动，这种差异常被称为 Stokes shift。

荧光传感和吸光度传感的读出逻辑不同。吸光度看的是入射光损失了多少，荧光看的是样品自己发出了多少光。因为背景可以通过波长和几何方向分开，荧光通常比吸收更灵敏，适合低浓度检测和生物成像。

不过荧光也有自己的问题。探针可能光漂白，样品可能有自发荧光，高浓度时可能发生自淬灭或内滤效应，环境 pH 和极性也会改变发光强度。因此荧光信号增强或减弱并不总能直接等同浓度变化，必须结合对照和校准。

图 12-5：FTIR 看的是分子振动方式

这张图用弹簧和小球表示分子振动。Stretch 是沿化学键方向伸长和缩短，bending 是键角改变。红外光的能量与这些振动能级差相匹配时，分子会吸收对应频率的红外光。

FTIR 的信息来自化学键，而不是简单的颜色或电子跃迁。不同官能团有特征振动频率，例如 C=O、O-H、N-H、C-H 等会出现在不同波数区域。因此 FTIR 常用于判断材料表面化学、聚合物组成、蛋白二级结构或传感膜是否修饰成功。

在传感器语境下，FTIR 可以作为检测方法，也可以作为材料表征工具。它的限制是水吸收强、复杂样品峰重叠、灵敏度相对荧光和电化学方法可能较低。理解 stretch 和 bending 后，就能明白 FTIR 谱峰为什么和化学键结构相关。

图 13-1：嗅觉系统把气味分子转换成神经信号

这张图用生物嗅觉系统解释气味传感的原型。空气中的 odorant molecules 进入鼻腔后，先接触鼻上皮中的 olfactory receptor cells。气味分子与受体结合后，受体细胞被激活并产生电信号，这些信号在 olfactory bulb 的 glomeruli 中汇聚，再被传到大脑更高级区域。

这不是一个“一个气味等于一个受体”的简单故事。真实嗅觉依赖组合编码：一个气味分子可能激活多个受体，一个受体也可能对多个气味分子有响应。大脑识别的是一组受体共同形成的响应模式，而不是某一个受体单独给出的 yes/no 结果。

把这张图放到传感器课程里，是为了引出电子鼻和复杂样品识别。气味样品通常是多分子混合物，很难靠一个完全特异的传感器解决；更常见的策略是设计一组交叉敏感的传感单元，让它们对不同气味产生不同指纹，再用模式识别方法判断样品类别。

图 13-2：气味识别靠 receptor 阵列的响应指纹

这张矩阵把“组合编码”变成了可读的传感器图。横向列是不同 receptor，纵向行是不同 odorant，粉色方块表示某个气味分子能激活某个受体。你会看到很多行不是只有一个方块，而是多个 receptor 同时响应；很多列也不是只响应一个 odorant，而是对一组相关分子都有响应。

这正是气味传感和传感阵列的核心。单个受体的选择性不一定足以区分所有分子，但整行响应模式可以成为气味的 fingerprint。两个分子如果在单个受体上反应相似，仍然可能因为整个受体阵列上的图案不同而被区分。

在工程系统中，receptor 可以换成导电聚合物、金属氧化物、功能化纳米材料、光学探针或生物识别元件。读出不再只是“浓度是多少”，还包括“这个样品属于哪一类”“混合物模式是否异常”。因此这张图连接了复杂样品、阵列式传感和数据统计，是新版 PPT 相比旧版新增的重点。

图 14-1：NIR 窗口来自血红蛋白和水吸收的夹缝

这张图解释为什么近红外光适合组织检测。可见光区域血红蛋白吸收很强，所以光很难深入组织。波长超过约 650 nm 后，氧合和脱氧血红蛋白的吸收明显下降；但当波长继续增大到约 950 nm 以上，水吸收又开始增强。

因此 650 到 950 nm 之间形成一个相对低吸收窗口，常称为 NIR-I 生物组织窗口。这个窗口不是因为光本身“更强”，而是因为组织里主要吸收体在这个范围吸收较低，光损失少一些。图中还标出 NIR-II，更长波长可减少散射，但水吸收、探针选择和探测器成本也要考虑。

这张图把光学传感和生物应用联系起来。体外比色可以选吸收最强的波长，但体内成像必须兼顾组织穿透、背景荧光、散射和安全性。看到近红外荧光题时，答案应从血红蛋白吸收下降、水吸收上升和组织窗口这三个因果环节展开。

图 14-2：波长越长，组织穿透通常越深

这张柱状图从另一个角度说明波长对组织穿透的影响。550 nm 的相对穿透深度最低，630 nm 增加，700 和 800 nm 更高。这与组织中吸收和散射随波长变化有关：短波更容易被散射和血红蛋白吸收，长波在近红外窗口里损失较小。

但这张图不能理解成波长越长永远越好。超过某些范围后，水吸收会增强；同时，长波长光学分辨率通常会降低，探针和探测器选择也更受限制。传感器设计永远是在穿透深度、分辨率、背景、毒性和仪器成本之间折中。

如果题目问为什么 800 nm 比 550 nm 更适合组织荧光检测，可以用这张图回答：800 nm 相对穿透深度更高，意味着更多激发光能到达深部，更多发射光能逃出组织，因此深部信号更容易被探测。

图 15-1：抗体检测的核心量是结合与解离

这张图把抗体结构和结合动力学放在一起。抗体通过可变区识别抗原，形成抗原-抗体复合物 AB。结合不是一次性事件，而是动态平衡：A 和 B 以 kon[A][B] 的速率结合成 AB，AB 又以 koff[AB] 的速率解离回 A 和 B。

平衡时结合速率等于解离速率，于是得到 KD = [A][B]/[AB] = koff/kon。KD 的单位是浓度，数值越小，表示在较低浓度下也能形成较多复合物，亲和力越强。这个量比“能不能结合”更有信息，因为几乎所有弱相互作用在足够高浓度下都可能有一些结合。

在免疫传感器中，亲和力只是一个维度。过弱的结合会导致灵敏度低，过强的结合可能让再生困难；非特异吸附会带来假阳性；样品基质会影响抗体结构和结合位点。因此评价抗体传感器时应同时看 KD、特异性、背景、动力学和表面固定化方式。

图 15-2：SPR 用折射率变化读出表面结合

这张图展示 SPR 的基本结构。偏振光通过棱镜照到金膜，在特定角度会激发表面等离子体共振。金膜表面固定有识别分子，样品从流道中流过；当目标分子结合到表面时，金膜附近的折射率发生变化，共振角或反射强度也随之改变。

下方的 sensorgram 是 SPR 的关键输出。样品注入后信号上升，表示目标正在结合；上升变慢并接近平台，表示结合接近平衡；换成缓冲液后信号下降，表示复合物解离。通过这些曲线可以估计 kon、koff 和 KD。

SPR 的优势是无标记、实时和可做动力学分析。它不需要给抗原接荧光或酶标记，所以更接近天然结合过程。限制是它对表面固定化、折射率变化和非特异吸附很敏感；如果样品中有大量蛋白粘到金膜上，信号也会上升，但那不一定是特异结合。

图 15-3：QCM-D 同时看质量加载和层的软硬

这张图展示 QCM-D 如何用石英晶体的振动来感知表面变化。石英晶体在交流电场下以稳定频率振荡，表面吸附分子后等效质量增加，振荡频率通常下降。图中 Δf 的变化就是频率响应。

QCM-D 还同时测耗散 ΔD。耗散反映振动能量损失，如果吸附层很软、含水多或具有黏弹性，它会消耗更多能量，ΔD 会明显变化。因此 QCM-D 不只是称质量，还能区分刚性薄层和柔软黏弹层，这对蛋白吸附、细胞粘附和多层膜组装特别有用。

把它和 SPR 比较可以更清楚：SPR 主要读表面折射率变化，QCM-D 主要读质量加载和黏弹性质。两者都能实时监测表面结合，但回答的问题不完全一样。一个实验中同时用 SPR 和 QCM-D，常能把“有多少东西结合”和“结合层是什么物理状态”分开。

图 16-1：三种 ELISA 流程的差别在“谁固定、谁竞争、谁带酶”

这张图把 indirect、sandwich 和 competitive ELISA 的流程画成三行。ELISA 的共同逻辑是：先让目标或识别分子固定在孔板表面，再通过抗原-抗体结合形成特异复合物，最后用酶标记和底物反应产生颜色。每一步 wash 的意义是洗掉未结合分子，降低背景。

Indirect ELISA 中孔板先包被抗原，样品中的特异抗体结合上去，再用酶标二抗识别样品抗体，所以它常用于测抗体。Sandwich ELISA 中孔板固定捕获抗体，目标抗原被捕获后再由检测抗体识别，两个抗体像三明治一样夹住目标，因此特异性高，适合蛋白抗原定量。

Competitive ELISA 的逻辑不同。样品中的目标和标记目标或抗体竞争有限结合位点，因此样品目标越多，最终颜色信号可能越低。这种反向关系很容易考。它适合小分子或只有一个表位的目标，因为小分子无法同时被两个抗体夹住。

图 17-1：侧向层析先看 C 线，再看 T 线

这张图是侧向层析试纸的结果判读。C 线是 control line，T 线是 test line。只有 C 线出现而 T 线不出现，说明测试有效但目标阴性；C 线和 T 线都出现，说明测试有效且目标阳性；如果 C 线没有出现，无论 T 线有没有，都不能相信结果。

C 线的作用是证明样品液体成功流过试纸、标记试剂被释放、毛细流动正常，并且试纸没有明显失效。它不是目标检测线，而是整个流程的内部质量控制。如果没有 C 线，你无法知道是样品没有目标，还是液体根本没流过去、试剂坏了或操作失败。

这张图也提醒你，快速检测的读数不是一个简单颜色判断，而是一个有流程控制的传感系统。实际使用中，T 线很浅可能代表低浓度目标、读数时间不合适或背景问题；但只要 C 线缺失，就必须判为 invalid，而不是勉强解释。

图 17-2：侧向层析是“流动 + 捕获 + 显色”的集成系统

这张图把侧向层析的内部结构拆开。样品先滴到 sample pad，随后通过毛细作用进入 conjugate pad。这里预先放有带标签的抗体或其他识别分子，标签可以是金纳米颗粒、乳胶颗粒或荧光团。样品中的目标与这些标记物结合后继续沿硝酸纤维素膜移动。

在 test line 位置，固定的捕获分子会抓住目标-标记复合物，标签聚集后形成可见线条；在 control line 位置，固定分子会抓住多余标记物或控制复合物，证明流动和试剂有效。最后 wicking pad 像吸水纸一样持续拉动液体，维持毛细流。

这张图正好体现 PPT 提到的纳米材料双重角色。金颗粒或荧光颗粒一方面连接识别分子，参与生物识别；另一方面提供颜色或荧光信号，是 transducer。侧向层析的优点是便宜、快速、无需复杂仪器；局限是定量能力和灵敏度通常不如实验室方法。

图 18-1：Aptamer 靠折叠后的三维结构识别目标

这张图展示 aptamer 的识别机制。左边的 aptamer 先是单链 DNA 或 RNA，随后折叠成特定二级和三级结构，再与目标分子结合形成 target-aptamer complex。这里的识别不只是简单的碱基互补，而是折叠后的空间形状、氢键、静电和疏水相互作用共同决定的。

因此 aptamer 在功能上有点像抗体：它能选择性识别蛋白、小分子、离子甚至细胞表面结构。但它又是核酸，具有化学合成方便、批间差异小、容易接荧光/电化学标签、可通过 SELEX 筛选等优点。

这张图也暗示 aptamer 的脆弱点。因为识别依赖折叠结构，所以温度、盐浓度、pH、核酸酶和样品基质都可能改变构象。设计 aptamer 传感器时，常把结合导致的构象变化转成荧光变化、电流变化或纳米结构聚集变化。

图 18-2：PCR 探针把序列识别变成荧光变化

这张图展示 PCR 中几种荧光探针策略。TaqMan 探针同时带有荧光基团和淬灭基团，探针完整时荧光被淬灭；当它与目标序列杂交并在扩增过程中被聚合酶水解，荧光基团与淬灭基团分离，信号增强。

FRET 探针依赖两个荧光基团之间的距离。只有当探针正确杂交到目标序列上，供体和受体距离合适，能量转移才会发生。第三类部分双链或单染料杂交探针则利用杂交状态改变荧光环境。共同点是：序列识别事件被转换成可实时读出的光信号。

这张图能帮助你理解 PCR 传感不是只靠“扩增变多”。扩增提供数量放大，探针提供特异读出。没有特异探针时，非特异扩增或引物二聚体也可能产生信号；有探针后，只有含目标序列的扩增产物更容易产生正确荧光变化。

图 19-1：电位器位移传感器把位置变成分压

这张图展示电位器式位移传感器。它的基本结构是一段电阻材料和一个可移动触点。触点位置改变时，被接入电路的电阻长度改变，电阻值随位移变化。若给整段电阻加电压，触点处输出电压就是一个分压结果。

如果电阻材料均匀，位移和电阻近似成线性关系，输出电压也可以近似线性反映位移。这就是最直观的位移到电信号转换：机械位置改变电阻，电阻改变电压。图中给出的 resistance sensitivity 和 voltage sensitivity 反映几何尺寸、电阻率和输入电流对输出变化的影响。

它的优点是结构简单、信号大、容易理解；缺点是滑动触点有机械接触，容易磨损、产生摩擦、接触噪声和寿命问题。因此它适合一些低成本、低频或教学场景，不适合所有高可靠、微小位移或长期植入应用。

图 19-2：应变片用电阻变化读机械变形

这张图展示 bonded strain gauge。应变片贴在结构表面，结构受拉伸时应变片也被拉长，导体长度增加、截面积减小，电阻通常增加；结构受压缩时相反，电阻减小。它测到的是应变，不是力本身。

为什么能用它测力？因为在已知结构和材料弹性关系的情况下，外力会导致特定位置产生应变，应变片测到电阻变化后，可以通过标定或力学模型反推出力、压力或弯矩。图里还说明应变片对横向力不敏感，方向性很重要。

实际应用中，应变片的电阻变化非常小，读出电路必须能分辨微小电阻变化，并尽量补偿温度带来的漂移。新版 PPT 没有展开桥路公式，所以这里抓住主因果即可：机械拉伸或压缩改变导体几何尺寸，几何尺寸改变电阻，电阻变化再被电路读成电信号。

图 19-3：电容传感可以测距离、液位和材料

这张图列出几种电容传感场景：接近检测、液位检测和平行板材料分析。它们看起来不同，但底层公式都是 C 约等于 epsilon A / d。只要被测对象改变有效面积 A、板间距离 d 或介电常数 epsilon，电容就会变化。

接近传感中，手指或物体靠近电极，相当于改变电场分布和耦合电容。液位传感中，空气被液体替代，介电常数改变，电容随液位上升而变。材料分析中，把不同材料放入平行板之间，可以通过电容变化推断介电性质。

电容传感的优点是结构简单、功耗低、可做柔性和微型器件；缺点是容易受寄生电容、湿度、人体接近、导线布置和屏蔽条件影响。答题时不要只背“电容传感器”，要指出具体是哪一个变量改变了电容。

图 20-1：一页图串起四类电容应用

这一页把电容传感的多个应用放在一起。左上是电容压力传感器：压力使膜片变形，极板间距 d 改变，电容随之变化。中上是液位传感器：液体高度变化改变两个电容 C1 和 C2 的比例，其中一个还可用于介电常数补偿。

右上是触摸传感。手指靠近电极时，会引入手指电容 CF，并改变原有传感电容 CS。下方的人体和穿戴式图形说明，身体与电极之间也可以形成电容耦合，因此胸腹运动、贴合程度、姿态和压力都可能通过电容变化读出。

这些应用的共同公式是 C 约等于 epsilon0 epsilonr ab / d。考试给出任何电容传感图，都可以先问：被测量改变了面积、间距还是介电常数？然后判断电容是增大还是减小。实际系统还必须处理寄生电容、温度、湿度和电极屏蔽问题。

图 21-1：压电效应和逆压电效应是一对

这张图解释压电效应和逆压电效应。某些材料在受到机械应力时，内部正负电荷中心发生相对位移，表面出现电荷或电场，这就是直接压电效应。反过来，如果对材料施加电压，材料会发生形变或振动，这就是逆压电效应。

图中列出石英晶体、蔗糖、DNA、丝和肌腱等例子，说明压电性并不限于传统陶瓷材料。交流电压会使晶体周期性形变，所以压电材料也常用于超声换能器、谐振器和执行器。

在传感器课程中，直接压电效应用来把压力、振动、冲击和声波转成电信号。它的优势是响应快、对动态变化灵敏；局限是静态电荷会泄漏，所以长期静态压力测量通常不是它最擅长的场景。

图 21-2：压电换能器用电极收集应力产生的电压

这张图把压电压力换能器画成一个夹在电极之间的压电块。外力从上方作用，材料产生极化和电荷分离，两侧电极收集电荷，外电路看到输出电压 E0。材料厚度、面积和力的方向都会影响输出。

这个结构说明压电传感器本质上不是电阻或电容变化，而是机械能直接转成电荷或电压。力越大、变化越快，输出信号通常越明显。电极的作用是把材料内部的电荷变化引出到测量电路。

实际使用时，压电传感器常需要高输入阻抗电荷放大器，因为产生的电荷量有限，容易被电路泄漏消耗。它非常适合测冲击、振动、脉动压力和声学信号；若题目强调高静压背景下的小动态变化，这正是压电压力传感器的典型优势。

图 21-3：动态压力曲线会转成交流样输出

这张图把压力随时间变化和压电输出联系起来。左边压力 P 在高静态背景上叠加微小波动，右边输出电压 Vout 随这些波动产生正负变化。箭头表示机械压力变化被转换成电信号波形。

压电传感器对变化特别敏感，是因为应力变化会不断重新分布电荷。对脉搏、振动、机械冲击、超声或快速压力波来说，这种动态电荷输出很有用。即使背景静压很高，只要有小的动态扰动，压电元件也可以给出清晰波形。

如果压力是长期恒定的，压电输出会因电荷泄漏和放大器漂移逐渐衰减，不能简单保持一个恒定电压。因此它和电容式或电阻式压力传感器的适用场景不同。判断题中看到 dynamic、pulsation、small pressure changes at high static pressure，就应该想到压电方案。

图 22-1：比色传感常需要 reference 通道

这张图展示带 reference 的比色传感思路。一个区域含有酶或识别反应，另一个区域作为参考。样品或环境变化可能同时影响光源、基底、温度和背景颜色，单独看一个区域容易把这些非特异因素误认为目标信号。

设置 reference 的意义是做差分或比值校正。目标反应只应显著改变 enzyme 区域，而光照变化、拍照角度变化或样品本身颜色可能同时影响两个区域。比较 enzyme 和 reference，就能削弱共同干扰，突出目标引起的特异变化。

这和电桥思想很像：不是直接相信一个绝对值，而是通过对照结构抵消背景。很多纸基传感、手机比色检测和可穿戴光学贴片都会使用参考通道。答题时如果看到 reference，不要忽略它，它通常是提高可靠性的关键设计。

图 22-2：光纤传感的三种读出：强度、波长、相位

这张图总结光纤传感的三种调制方式。强度调制中，被测量改变光的损耗或耦合效率，例如压力让光纤弯曲，输出光强降低。它简单直观，但光源波动、连接损耗和弯折都可能影响读数。

波长调制中，被测量改变反射或透射的中心波长，典型例子是光纤 Bragg 光栅。应变或温度改变光栅周期和有效折射率，使反射波长移动。因为读的是波长位置而不是光强大小，所以它对光源强度波动更鲁棒，也适合多点复用。

相位调制中，被测量改变光程差，干涉仪把相位变化转换成强度或条纹变化。它的灵敏度很高，但系统搭建和解调更复杂。看到光纤题时，应先判断图中变化的是光强、波长还是相位，再讨论优缺点和应用场景。

图 23-1：Hall sensor 把磁场变成横向电压

这张图展示 Hall effect 的基本原理。电流沿半导体片流动时，如果有垂直方向的磁场，运动载流子会受到洛伦兹力向一侧偏转。载流子积累在一边后，横向形成电势差，这个电压就是 Hall voltage VH。

Hall 传感器的输入是磁场，输出是横向电压。电流越大、磁场越强，Hall 电压通常越明显；材料载流子浓度和类型会影响灵敏度和极性。图中 p-type semiconductor 说明载流子类型也会影响电压方向。

它可以直接测磁场，也可以间接测位移、角度、电流或生物结合事件。例如把磁铁放在可移动结构上，结构位移会改变 Hall 传感器处的磁场；把磁纳米颗粒接到生物目标上，目标结合会带来局部磁信号。这就是 Hall sensor 从物理量走向生物检测的桥梁。

图 23-2：磁纳米颗粒让 Hall 阵列能做生物检测

这张图展示把 Hall 传感器用于生物检测的思路。表面先固定识别分子，目标结合后再引入 magnetic nanoparticles。磁纳米颗粒相当于标签，本身带来局部磁场，底下的 Hall-effect device array 可以检测这些磁场变化。

这里的生物特异性来自抗体、核酸探针或其他识别层；Hall 芯片只负责把磁标签的存在转换成电信号。换句话说，Hall sensor 并不认识蛋白或病毒，它认识的是磁场。生物事件必须先被磁纳米颗粒标记，才能被 Hall 阵列读出。

这种设计的优点是磁背景通常较低，样品本身不像荧光那样容易自发发光；缺点是需要可靠的磁标签、洗涤和表面化学。它是课程中“纳米材料 + 生物识别 + 物理传感器”结合的典型例子。

图 23-3：DNA 杂交可作为 Hall 检测前端识别事件

这张图画的是 DNA 杂交识别。probe DNA 固定在表面，样品中的 complementary target DNA 如果序列互补，就会与 probe 杂交形成双链结构。这个过程提供了核酸检测的序列选择性。

单纯 DNA 杂交本身不一定产生强电信号，所以实际传感器常要把它连接到转导机制上。可以用荧光探针、酶标记、纳米颗粒、场效应晶体管，也可以像上一张图那样用磁颗粒和 Hall 阵列读出。

这张图的上下文是：核酸检测不只 PCR 一种方式。PCR 用扩增提高灵敏度；表面杂交传感器则把互补配对直接放在芯片表面。两者都依赖碱基配对，但信号放大和读出方式不同。

图 23-4：可穿戴 Hall 传感把形变转成磁场变化

这张图展示 Hall sensor 在可穿戴结构中的应用。手部夹板或柔性结构发生弯曲时，内部磁铁和 Hall 传感器的相对位置改变，传感器处的磁场强度和方向也随之变化。芯片读到的是磁场变化，但我们真正关心的是手部运动或关节状态。

这说明很多传感器是间接测量。目标量是运动、形变或压力，但中间通过磁铁把机械变化转换成磁场变化，再由 Hall 传感器转换成电压。这样的结构可以避免直接机械接触磨损，也能把传感元件封装在柔性材料中。

设计时必须考虑磁铁位置、弹性体刚度、传感器线性范围和外部磁场干扰。如果磁铁太近可能饱和，太远信号太弱；如果弹性体迟滞大，读数会出现路径依赖。这些都是从图中结构可以推出来的工程问题。

图 24-1：MEMS 加速度计靠微梁和活动质量块工作

这张显微图展示 MEMS 加速度计中的固定梁和活动梁，尺度只有约 10 微米。MEMS 器件把机械结构做在芯片上，活动质量块在加速度作用下发生微小位移，周围的梁结构提供弹性支撑。

加速度本身不是电信号。器件需要把质量块位移转成可读量，常用方式是电容变化：固定电极和活动电极之间距离变化，差分电容随加速度改变。也可以用压电、压阻或热方式读出，具体取决于结构设计。

这张图说明 MEMS 的核心不是“很小”这么简单，而是把机械结构、传感读出和微加工集成在一起。小尺寸带来低功耗、可批量制造和便携性，也带来封装、温漂、噪声、机械冲击和微加工公差等问题。

图 24-2：MEMS 是传感器和执行器的平台，不是一种单一原理

这张图给出 MEMS 的定义和主要换能类型。MEMS 是微尺度器件平台，可以用于 sense、transport 或 produce a change，也就是既可以做传感器，也可以做执行器。外部机械、电或化学刺激进入微结构后，被转换成可测信号或产生响应。

图中列出三类主要 transducers：capacitive、piezoelectric 和 thermal，另外还有 microfluidic。电容式常见于加速度计和压力传感；压电式适合振动、超声和动态压力；热式可用于流量、气体或微执行；微流控则把液体处理和检测集成到芯片上。

所以 MEMS 不是某一种单一传感原理，而是一类制造和集成平台。答题时如果看到 MEMS，应继续说明它具体用什么换能机制。说“这是 MEMS，所以能测加速度”还不够，应该说明活动质量块如何位移、位移如何变成电容或其他信号。

这张图把医疗器械按 FDA 风格分成三类。分类依据不是技术是否先进，而是设备风险和保证安全有效所需的监管控制强度。Class I 是低风险设备，主要依靠 general controls，例如牙线、医用剪刀和牙科注射器。

Class III 是高风险设备，通常维持生命、植入人体或失效可能导致严重伤害，因此需要 premarket approval。体外除颤器和人工心脏瓣膜属于这一类。把这页放在课程末尾，是为了提醒你：传感器从实验室走向医疗应用时，不只是灵敏度和论文指标，还必须面对风险、验证、监管和临床安全。

1. 传递函数与校准：传感器到底在“翻译”什么

传感器不是直接给你“真实世界答案”，它先给出一个信号。传递函数描述真实刺激 \(X\) 与输出信号 \(S\) 的关系，校准则是用已知标准样本把这个关系估出来。

1.1 从被测量到显示值

典型链路是：measurand 产生 physical measurement variable \(X\)，传感器输出 signal variable \(S\)，显示或算法给出 measurement \(M\)。考试时如果让你“说明传感器工作过程”，不要只说材料名，要按这条链路说明输入、换能机制、输出和校准。

\[X \xrightarrow{\text{sensor}} S \xrightarrow{\text{calibration/display}} M\]

1.2 为什么不是所有响应都线性

线性响应 \(S=a+bX\) 最容易用，因为斜率就是灵敏度。但很多传感器受反应动力学、扩散、吸附位点饱和、电子学放大范围限制，会出现对数、指数、多项式或饱和响应。看到非线性响应时，先问：能否在小范围内线性近似？是否需要取对数或用标准曲线插值？

法
校准题模板：先写 \(S=f(X)\)，说明 \(X\) 和 \(S\) 的单位；再用标准点拟合参数；最后把未知样品的 \(S\) 代回求 \(X\)。如果样品超出校准范围，不能外推当作可靠结果。

例题 1：Beer-Lambert Law 作为传递函数

定量

题目：某物质在固定波长下 \(\varepsilon=2.0\times10^4\ \mathrm{L\,mol^{-1}\,cm^{-1}}\)，比色皿光程 \(l=1.0\ \mathrm{cm}\)。测得 \(I_0/I=10\)。求浓度。

  1. 先把信号写成吸光度：\(A=\log_{10}(I_0/I)=\log_{10}10=1\)。
  2. 把 Beer-Lambert Law 看作传递函数：\(A=\varepsilon l c\)。
  3. 代入：\(c=A/(\varepsilon l)=1/(2.0\times10^4\times1.0)=5.0\times10^{-5}\ \mathrm{M}\)。

解释：这里输入 \(X\) 是浓度 \(c\)，输出 \(S\) 是吸光度 \(A\)。斜率 \(\varepsilon l\) 越大，同样浓度变化引起的吸光度变化越大，灵敏度越高。

2. 传感器特性：如何判断一个测量“好不好”

传感器特性分静态和动态。静态特性回答“稳态值准不准、噪声大不大、能测多低、多宽”；动态特性回答“输入改变后多久跟上、是否超调、是否振荡”。

2.1 静态指标总表

指标一句话定义直觉常见错误
Accuracy测量均值接近真值的程度。靶心图中点群中心离靶心近。把 accuracy 与 precision 混用。
Precision重复测量彼此接近的程度。点群聚得紧。精密但不准确是可能的。
Sensitivity输出随输入变化的斜率。校准曲线越陡，单位输入变化越容易被看到。把 sensitivity 与 specificity 混淆。
Specificity识别目标而不响应非目标的能力。健康者被判阴性的比例高。只看阳性样本，不看假阳性。
Linearity输出与输入是否近似直线关系。线性范围内可用一个斜率描述。把饱和区也拿来线性拟合。
Hysteresis输入上升和下降路径得到不同输出。加载/卸载曲线不重合。只做单方向校准。
LOD能可靠“看见”的最低量。信号刚超过噪声。把 LOD 当成可准确定量的最低点。
LOQ能可靠“定量”的最低量。通常高于 LOD。报告低于 LOQ 的精确数值。
SNR信号相对噪声强度。越大越容易识别真实峰。只看峰高，不看基线噪声。
Repeatability同条件重复结果一致性。同人同仪器同环境。与 reproducibility 混用。
Reproducibility不同条件下结果一致性。不同人、不同仪器、不同实验室。只在一个实验室验证就说可复现。

2.2 灵敏度与特异性：用混淆矩阵别混

\[ \text{sensitivity}=\frac{TP}{TP+FN},\quad \text{specificity}=\frac{TN}{TN+FP},\quad \text{PPV}=\frac{TP}{TP+FP},\quad \text{NPV}=\frac{TN}{TN+FN} \]

PPT 中列出 TP、FP、FN、TN。重点是分母不同：sensitivity 的分母是所有真正有病者，specificity 的分母是所有真正无病者。阳性预测值 PPV 和阴性预测值 NPV 虽不在 PPT 主图中，但常和前两者一起出现，受患病率影响很大。

例题 2：从混淆矩阵计算指标

诊断统计

题目：100 名患病者中检测阳性 92 人，100 名无病者中检测阳性 8 人。求 sensitivity 和 specificity。

  1. 患病且阳性：\(TP=92\)。患病但阴性：\(FN=8\)。
  2. 无病但阳性：\(FP=8\)。无病且阴性：\(TN=92\)。
  3. \(\text{sensitivity}=92/(92+8)=92\%\)。
  4. \(\text{specificity}=92/(92+8)=92\%\)。

易错点：如果题目把总人数、患病人数、阳性人数混在一起给，先画四格表再算，不要直接拿阳性总数当分母。

2.3 噪声、LOD、LOQ 与 SNR

LOD 和 LOQ 的核心不是“有没有信号”，而是信号相对噪声是否足够可靠。PPT 图中 Peak A 到达 LOD，只能说明存在可检出信号；Peak B 到达 LOQ，才适合给出可信浓度数值。常见经验是 LOD 约为空白均值加 3 倍噪声标准差，LOQ 约为空白均值加 10 倍噪声标准差；若把信号换成浓度，则除以校准曲线斜率。

例题 3：用噪声和斜率估算 LOD/LOQ

常用补充

题目：空白噪声标准差 \(\sigma_b=0.015\ \mathrm{A.U.}\)，校准曲线斜率 \(m=0.30\ \mathrm{A.U./nM}\)。估计 LOD 和 LOQ。

  1. \(LOD\approx 3\sigma_b/m=3\times0.015/0.30=0.15\ \mathrm{nM}\)。
  2. \(LOQ\approx 10\sigma_b/m=10\times0.015/0.30=0.50\ \mathrm{nM}\)。

解释：增大斜率或降低噪声都会降低 LOD/LOQ。单纯放大信号如果同时放大噪声，不一定改善 LOD。

2.4 动态特性：一阶系统与二阶系统

一阶系统：水银温度计

PPT 用水银温度计说明 sensitivity \(k\) 与 time constant \(\tau\) 的权衡。更大的 bulb volume \(V_b\) 提高位移灵敏度，但也让系统热容量变大，响应变慢；更大的接触面积 \(A_b\) 和换热系数 \(U\) 有助于降低 \(\tau\)。

\[k=\frac{K_{ex}V_b}{A_c},\qquad \tau=\frac{\rho C V_b}{UA_b}\]

二阶系统：阶跃响应

二阶响应常见振荡。rise time 是从 10% 到 90% 的时间；response time 或 settling time 是进入并保持在误差带内的时间；overshoot 是最大峰值超过稳态值的量；attenuation 描述相邻峰值衰减。

\[\psi=\frac{\alpha-\alpha_1}{\alpha}\times100\%\]
辨
静态 vs 动态：如果题目问“稳态时读数是否接近真实值”，这是静态准确性；如果题目问“突然输入后多久到达稳定读数”，这是动态响应。一个传感器可以稳态很准但响应很慢。

3. 生物标志物：先明确“测到的特征代表什么”

新版 PPT 在这一页强调 biomarker 的定义和类型。生物标志物是能被测量、并指示正常生物过程、病理过程、暴露响应或治疗响应的特征。传感课程关心的不只是“能不能检测”，还要说明被测特征对应的是分子、组织、影像还是生理功能。

Molecular

分子标志物，如血糖、蛋白、核酸、代谢物。传感器常直接识别分子结构或反应产物。

Histologic / Radiographic

组织学或影像学标志物，如肿瘤组织形态、肿瘤大小。它们常通过图像或病理流程获得。

Physiologic

生理标志物，如血压、心率、体温。常与压力、位移、光学或电生理传感器相关。

3.1 为什么分类很重要

同样叫 biomarker，检测链路可能完全不同。Molecular biomarker 往往需要化学或生物识别元件，例如酶、抗体、aptamer 或核酸探针；radiographic biomarker 依赖成像和图像定量；physiologic biomarker 常由压力、位移、光学或电生理传感器获得。先判断 biomarker 类型，才能继续选择合适的 transducer、校准方式和临床解释方式。

答题时不要只写“biomarker 是疾病标志物”。更完整的说法是：它必须可测量，并且这个可测特征要能指示某种生物状态或干预响应。血糖、肿瘤大小、血压分别落在不同类型中，所以后续课程才会同时出现电化学、光学、免疫、核酸和物理传感器。

4. 酶传感与电化学：从血糖检测到安培型传感器

酶传感的基本想法是：酶把目标底物转成产物，产物或反应过程引起可测电信号。血糖传感器是最经典例子。

4.1 Michaelis-Menten 方程的物理含义

\[v_0=\frac{V_{\max}[S]}{K_M+[S]}\]

\(v_0\) 是初始反应速率，\([S]\) 是底物浓度，\(V_{\max}\) 是酶位点全部被充分利用时的最大速率，\(K_M\) 是速率达到 \(V_{\max}/2\) 时的底物浓度。它告诉你：低浓度时速率随浓度近似线性，高浓度时酶位点接近饱和，继续增加浓度也不能显著增加速率。

浓度范围近似传感意义
\([S]\ll K_M\)\(v_0\approx (V_{\max}/K_M)[S]\)适合定量，响应近似线性。
\([S]=K_M\)\(v_0=V_{\max}/2\)\(K_M\) 可视为酶对底物亲和/工作范围的尺度。
\([S]\gg K_M\)\(v_0\approx V_{\max}\)系统饱和，高浓度区分能力下降。

4.2 三类电化学读出

Potentiometric

测电压。典型问题是某种离子活度改变电极电位，例如 pH 电极、离子选择电极。

Amperometric

测电流。目标反应在电极上氧化还原，电流与反应速率和物质通量相关。葡萄糖传感器重点属于这一类。

Conductometric

测电导。反应改变溶液中离子浓度或迁移能力，从而改变电导。

4.3 第一代葡萄糖生物传感器

PPT 中给出的核心反应链是：

\[ \text{glucose}+O_2 \xrightarrow{GO_x} \text{gluconolactone}+H_2O_2 \]

生成的 \(H_2O_2\) 在 Pt 工作电极上被氧化：

\[ H_2O_2 \xrightarrow{\text{Pt anode}} O_2+2H^+ +2e^- \]

电极收集电子形成电流，电流大小与 \(H_2O_2\) 产生速率相关，也就与葡萄糖浓度相关。第一代传感器的弱点也来自这里：它依赖氧气，并且高电位氧化 \(H_2O_2\) 时可能受到其他可氧化物质干扰。

例题 4：判断葡萄糖传感器的输入、转导和输出

答题模板

题目：简述第一代 GOx 葡萄糖传感器如何测量血糖。

  1. 识别层：葡萄糖氧化酶 GOx 对葡萄糖有选择性，催化葡萄糖与 \(O_2\) 反应。
  2. 化学转化：葡萄糖被氧化生成 gluconolactone，同时产生 \(H_2O_2\)。
  3. 电化学转导：\(H_2O_2\) 在 Pt 电极上氧化产生电子，形成可测电流。
  4. 校准定量：用已知葡萄糖浓度建立电流-浓度曲线，再由未知样品电流反推浓度。
  5. 限制：氧气供应、酶活性、扩散、干扰物和电极污染都会影响结果。

5. 分子光谱、气味传感与近红外荧光

新版 PPT 在光谱总览后加入了气味/嗅觉受体图。光谱传感的共同思想是分子和光相互作用会改变光的强度、波长、相位或时间特性；气味传感则强调复杂分子混合物如何通过一组非完全特异的受体形成可识别模式。

方法主要测什么典型输出适合回答的问题
UV-vis电子跃迁导致的吸收吸光度 \(A\)样品在某波长吸收多少，浓度是多少。

5.1 Beer-Lambert Law 的使用边界

Beer-Lambert Law 把浓度与吸光度联系起来，但它不是无限适用。高浓度时分子间相互作用、散射、杂散光、仪器动态范围都可能破坏线性。因此定量时必须有标准曲线，并说明样品落在线性范围内。

错
常见错误：把 \(I\) 和 \(I_0\) 颠倒。吸光度定义为 \(A=\log_{10}(I_0/I)\)。样品吸收越强，透过光 \(I\) 越小，\(A\) 越大。

5.2 气味传感：单个受体不够，关键是响应模式

新版第 13 页左侧用嗅觉系统说明气味识别的生物原型：odorant 分子进入鼻腔后，与 olfactory receptor cells 上的受体结合，受体细胞产生电信号，信号在 glomeruli 中汇聚，再传到更高级脑区。这里的重点不是某一个受体只识别某一种气味，而是许多受体对许多 odorants 形成组合响应。

右侧的 odorant-receptor 矩阵可以看作传感器阵列：行是不同气味分子，列是不同 receptor，粉色格子表示某个受体对某个 odorant 有响应。一个 odorant 往往激活多个 receptor，一个 receptor 也可能响应多个 odorants。最终可区分的是整行响应图案，而不是单个格子。这就是电子鼻、气味传感和复杂样品模式识别的核心思路：用阵列产生指纹，再用统计或机器学习方法分类。

5.3 为什么 650-950 nm 是组织光学窗口

PPT 的关键结论是：可见光尤其短波段被 hemoglobin 强吸收；当波长超过 650 nm，血红蛋白吸收显著降低；但超过 950 nm 后，水吸收明显增加。因此 650-950 nm 之间吸收较小，光能在组织中传播更深，适合近红外荧光成像和体内检测。

波段主要限制传感意义
< 650 nm血红蛋白吸收强，散射也明显。穿透浅，更适合表面或透明样品。
650-950 nm吸收相对较低。组织光学窗口，适合深部荧光检测。
> 950 nm水吸收增强。穿透受到水吸收限制，热效应需考虑。

6. 免疫检测、ELISA 与纳米材料

抗体传感的核心是分子识别：抗体与抗原特异结合，结合事件通过光、电、质量、折射率或颜色变化读出。

6.1 抗体结合与 \(K_D\)

把抗体和抗原分别记为 \(A\) 和 \(B\)，复合物为 \(AB\)。结合速率与 \([A][B]\) 成正比，解离速率与 \([AB]\) 成正比。平衡时：

\[ k_{on}[A][B]=k_{off}[AB],\qquad K_D=\frac{[A][B]}{[AB]}=\frac{k_{off}}{k_{on}} \]

\(K_D\) 越小，说明在较低浓度下也能形成较多复合物，亲和力更高。考试中如果问“哪个抗体更好”，不能只看是否结合，还要看 \(K_D\)、交叉反应、稳定性和检测背景。

6.2 SPR 与 QCM-D

SPR

Surface plasmon resonance 通过表面折射率变化检测结合事件。抗原抗体结合改变金膜附近折射率，使共振角或响应信号变化。优点是可实时、无标记监测结合和解离。

QCM-D

Quartz crystal microbalance with dissipation 通过石英晶体频率变化和耗散变化反映表面质量加载与层的黏弹性。频率下降通常意味着表面吸附质量增加；耗散变化帮助判断层是刚性还是软/含水。

6.3 ELISA 五种类型

类型基本流程适合对象结果解释
Direct ELISA抗原固定，酶标一抗直接结合。流程短、目标明确。颜色越深通常目标越多。
Indirect ELISA抗原固定，一抗结合，再加酶标二抗。检测抗体或提高信号。二抗提供放大，但增加非特异风险。
Sandwich ELISA捕获抗体固定，夹住抗原，再用检测抗体读出。蛋白、抗原定量，特异性高。需要抗原有两个可被识别的表位。
Competitive ELISA样品目标与标记目标竞争结合位点。小分子或单表位目标。样品越多，常见读出信号反而越低。
Multiplex ELISA同时检测多个目标。细胞因子、多标志物面板。需要防止交叉反应和信号串扰。

6.4 Lateral flow assay：为什么一条线阳性、一条线有效

侧向层析试纸由 sample pad、conjugate pad、nitrocellulose membrane、wicking pad 等组成。样品沿毛细作用流动，带着标记抗体或纳米颗粒移动。test line 上固定的识别分子捕获目标复合物，显示阳性；control line 捕获流过的标记物，证明液体流动和试剂有效。若 control line 不出现，无论 test line 如何，都应判为无效。

7. 核酸检测：Aptamer 与 PCR 荧光探针

核酸检测把“序列互补”和“扩增”作为核心放大机制。PPT 同时把 aptamer 放在这里，因为 aptamer 本身是可折叠的核酸识别分子，能像抗体一样结合目标。

Aptamer

Aptamer 是筛选得到的短 DNA/RNA 序列。它不是靠 Watson-Crick 配对识别另一条核酸，而是折叠成三维结构后与蛋白、小分子或细胞表面目标结合。优点是可化学合成、易修饰、批间差异小；限制是结构受离子强度、温度和样品基质影响。

PCR probe

TaqMan 探针使用双标记荧光水解探针，扩增时探针被聚合酶水解，荧光与淬灭基团分离，信号上升。FRET 杂交探针依赖供体和受体距离变化。共同点是把序列特异性转换成荧光信号。

7.1 这页的共同逻辑：识别事件必须被转成可读信号

Aptamer 的识别来自折叠后的三维结构，PCR probe 的识别来自序列互补和扩增过程中的荧光变化。二者都不是“看见分子本身”，而是把结合、杂交、水解或构象变化转成光学、电化学或其他可读信号。新版 PPT 不再展开病毒诊断路线图后，这一节的重点就更集中：核酸既可以作为被检测对象，也可以作为识别元件和信号转换元件。

8. 物理传感器与 MEMS：把力、位移、压力、磁场转成电信号

新版 PPT 的物理传感器复习页聚焦电位器、应变片、电容传感，后续再接压电、量热、光纤、Hall 和 MEMS。学习重点是“输入变量改变了哪个可读物理量”。只要能说清电阻、电容、电压、频率、相位或磁场如何随输入变化，就抓住了主线。

8.1 电阻式：电位器与应变片

电位器位移传感器

滑动触点位置改变有效电阻，输出电压按分压关系变化。优点是直观、成本低；缺点是机械接触带来磨损、摩擦和寿命问题。

应变片

拉伸使导体长度增加、截面积减小，电阻通常增大；压缩时电阻减小。应变片对轴向应变敏感，对横向力可能不敏感，因此安装方向很关键。

新版复习页没有展开桥路公式，因此这里按 PPT 主图掌握到“位移改变电阻分压，应变改变导体电阻”即可。实际工程中小电阻变化常需要差分读出和温度补偿，但答这份 PPT 的核心应落在输入-电阻-电压/电信号的因果链上。

8.2 电容式：距离、液位和介电性质

电容传感

\[C\approx \varepsilon_0\varepsilon_r\frac{ab}{d}\]

压力或触摸可以改变有效板间距 \(d\) 和电场分布，液位可以改变介电常数 \(\varepsilon_r\)，材料分析可以把待测材料放入平行板之间，通过电容变化推断介电性质。新版第 19 页只保留电容传感的三类示例，所以答题时重点说明到底是面积、间距还是介电常数发生了变化。

8.3 压电传感器

压电材料在机械应力下产生电荷/电压；反过来，施加电场也会让材料形变，这叫逆压电效应。PPT 中举例包括 quartz crystals、sucrose、DNA、silk、tendon。压电压力传感器特别适合动态、快速或微小压力变化，因为变化越快越容易产生明显电荷输出；但纯静态长期压力测量会受到电荷泄漏和漂移限制。

答
压电题答法：先说“机械应力导致极化/电荷分离”，再说“电极收集电荷形成电压”，最后指出适合动态压力、振动和脉动测量。

8.4 光纤、Hall 与 MEMS

类型输入改变什么输出读什么典型优点
Intensity-modulated fiber弯曲、压力或吸收改变光强。输出光强。结构简单，远距离传输。
Wavelength-modulated fiber应变/温度改变光栅周期或折射率。反射/透射波长。抗强度波动，适合多点复用。
Phase-modulated fiber光程差变化。干涉相位。高灵敏度。

MEMS微梁、质量块、薄膜受力或加速度变化。电容、压电、热或微流控信号。小型化、批量制造、可集成。

例题 5：电容压力传感器方向判断

物理直觉

题目：平行板电容压力传感器中，压力使两极板距离 \(d\) 减小。输出电容如何变化？

  1. 写核心公式：\(C=\varepsilon A/d\)。
  2. 压力增大导致 \(d\) 减小，\(\varepsilon\) 和 \(A\) 近似不变。
  3. 因此 \(C\) 增大。若电路把电容转成电压或频率，还需看后端读出电路方向。

最后一页把课程引到转化与监管。医疗器械分类不是按技术先进程度，而是按风险和所需监管控制强度。

10. 综合题库：按答案思路训练

下面的题不追求覆盖所有细枝末节，而是训练 PPT 最可能考的概念链路。建议先自己回答，再展开参考答案。

题 1：什么是 transfer function？为什么校准曲线很重要？
Transfer function 描述输入刺激 \(X\) 与输出信号 \(S\) 的关系，即 \(S=f(X)\)。校准曲线用已知标准样品确定 \(f\) 的形式和参数，使未知样品的信号可以反推浓度、压力或其他被测量。没有校准，信号只是电流、电压或光强，不能直接等同真实量。
题 2：accuracy 和 precision 的区别是什么？
Accuracy 关注测量均值离真值多近；precision 关注重复测量彼此多接近。一个系统可以 precision 高但 accuracy 低，例如所有点都聚在一起但偏离靶心；也可以 accuracy 较好但 precision 低，例如点分散但均值接近真值。
题 3：LOD 和 LOQ 有什么区别？
LOD 是最低可检出量，说明信号能从噪声中被看见；LOQ 是最低可定量量，说明信号足够高，可以给出可信数值。LOQ 通常高于 LOD。报告低于 LOQ 的精确定量值是不严谨的。
题 4：为什么水银温度计的灵敏度和响应速度存在权衡？
更大的 bulb volume \(V_b\) 会让温度变化引起更大的液柱位移，因此提高灵敏度；但它也增加热容量，使时间常数 \(\tau=\rho C V_b/(UA_b)\) 增大，响应变慢。增大接触面积 \(A_b\) 或换热系数 \(U\) 可以缩短时间常数。
题 5：Michaelis-Menten 方程中 \(K_M\) 的意义是什么？
\(K_M\) 是反应速率达到 \(V_{\max}/2\) 时的底物浓度。它给出酶传感器从线性区走向饱和区的浓度尺度。低于 \(K_M\) 很多时，速率近似与浓度成正比；高于 \(K_M\) 很多时，速率接近 \(V_{\max}\)。
题 6：第一代葡萄糖传感器为什么属于 amperometric sensor？
因为它最终测量的是电极上的氧化还原电流。GOx 催化葡萄糖生成 \(H_2O_2\)，\(H_2O_2\) 在 Pt 电极上氧化产生电子，电流与反应速率相关。通过校准可由电流反推葡萄糖浓度。
题 7：为什么近红外 650-950 nm 适合组织检测？
在 650 nm 以下，血红蛋白吸收较强；在 950 nm 以上，水吸收明显增强。650-950 nm 区间吸收相对较低，光可以在组织中传播更深，因此称为组织光学窗口。
题 8：\(K_D\) 越大越好吗？
不是。\(K_D=[A][B]/[AB]=k_{off}/k_{on}\)，数值越小表示较低浓度下也能形成较多复合物，亲和力越强。高 \(K_D\) 通常意味着结合弱或容易解离。
题 9：sandwich ELISA 为什么通常特异性高？
因为目标抗原需要同时被捕获抗体和检测抗体识别，相当于双重识别。但它要求抗原有至少两个可同时识别的表位，因此小分子或单表位目标不一定适合。
题 10：侧向层析试纸的 control line 有什么作用？
control line 证明样品流动、标记试剂释放和反应体系基本有效。若 control line 不出现，即使 test line 出现，也应判为无效测试。
题 11：PCR 荧光探针为什么能提高检测特异性？
PCR 扩增负责把目标序列数量放大，荧光探针负责确认扩增产物是否包含目标序列。TaqMan 探针只有在正确杂交并被聚合酶水解后才释放荧光；FRET 探针则要求探针与目标序列形成合适空间距离。这样可以减少非特异扩增或引物二聚体带来的误读。
题 12：为什么气味传感常用阵列而不是单个传感器？
气味样品通常是多分子混合物，单个受体或单个传感材料很难对所有 odorant 完全特异。阵列中每个单元对不同分子有交叉敏感性，多个单元共同形成响应指纹。分类时看的不是某一个通道，而是整组响应模式。
题 13：电容式压力传感器中压力增大导致间距变小，电容如何变化？
由 \(C=\varepsilon A/d\)，若 \(A\) 和 \(\varepsilon\) 不变，\(d\) 减小会使 \(C\) 增大。
题 14：压电传感器为什么适合动态压力或振动？
压电材料在应力变化时产生电荷/电压，动态载荷会持续产生可测信号；静态载荷下电荷可能泄漏，读数易漂移，因此压电传感器尤其适合快速变化、脉动和振动测量。
题 15：Hall sensor 的输入和输出分别是什么？
输入是垂直于电流方向的磁场，输出是横向 Hall voltage。磁场使载流子受洛伦兹力偏转，在横向形成电势差。
题 16：MEMS 的三类主要 transducers 是什么？
PPT 列出三类主要 transducers：capacitive、piezoelectric、thermal；另外还可包括 microfluidic。MEMS 常把微结构、传感器和执行器集成在微尺度芯片上。
