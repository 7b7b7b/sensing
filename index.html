公式速查：先记“变量意义”，再记等号

传递函数\[S=f(X)\]

输入 \(X\) 是被测刺激，输出 \(S\) 是传感器信号。校准的目标是反过来由 \(S\) 估计 \(X\)。

Beer-Lambert Law\[A=\log_{10}\frac{I_0}{I}=\varepsilon l c\]

\(A\) 为吸光度，\(l\) 为光程，\(c\) 为浓度，\(\varepsilon\) 为摩尔吸光系数。

混淆矩阵\[\text{sensitivity}=\frac{TP}{TP+FN},\quad \text{specificity}=\frac{TN}{TN+FP}\]

前者看患病者中检出多少，后者看健康者中排除多少。

常用 LOD/LOQ 估计\[LOD\approx \frac{3\sigma_b}{m},\quad LOQ\approx \frac{10\sigma_b}{m}\]

\(\sigma_b\) 是空白噪声标准差，\(m\) 是校准曲线斜率。PPT 给了概念图，这里补常用计算式。

一阶温度计示例\[k=\frac{K_{ex}V_b}{A_c},\quad \tau=\frac{\rho C V_b}{UA_b}\]

大 bulb volume 提高灵敏度，但增大时间常数；接触面积可改善响应速度。

二阶响应指标\[t_r,\quad t_s,\quad \alpha,\quad \psi=\frac{\alpha-\alpha_1}{\alpha}\times 100\%\]

分别描述上升时间、稳定时间、超调和相邻峰值衰减。

Michaelis-Menten\[v_0=\frac{V_{\max}[S]}{K_M+[S]}\]

\([S]\ll K_M\) 时近似一阶；\([S]\gg K_M\) 时趋于饱和。

抗体亲和力\[K_D=\frac{[A][B]}{[AB]}=\frac{k_{off}}{k_{on}}\]

\(K_D\) 越小，结合越强；它的单位是浓度。

电容传感\[C\approx \varepsilon_0\varepsilon_r\frac{ab}{d}\]

面积和介电常数增大，电容增大；板间距增大，电容减小。

Wheatstone bridge\[V_{TH}=V\left(\frac{R_1}{R_1+R_3}-\frac{R_2}{R_2+R_4}\right)\]

用于把小电阻变化转成可测电压差。

逐图精讲：把 PPT 里的图拆开看

这一节是对前面讲义的补强。PPT 是精简版，很多“真正要懂的东西”藏在图里：坐标轴、箭头、反应物、检测线、电极、梁结构和公式变量。下面按 PDF 页码把核心图裁出来逐个解释。

图 3-1：传感链路不是“传感器等于答案”

  • 图里：左边的 measurand 是真实世界的被测对象，中间 sensor 把物理测量变量 \(X\) 转成信号变量 \(S\)，右边 display 再把信号变成读数 \(M\)。
  • 读法：考试写工作原理时要按“被测量 - 换能 - 信号 - 显示/算法”四步写。只说“用了某材料”不够。
  • 考点：校准发生在 \(S\) 与 \(X\) 或 \(M\) 的关系上；误差可能来自传感器、显示系统，也可能来自被测对象本身的扰动。

图 3-2：Beer-Lambert Law 是一个标准传递函数

  • 图里：\(A=\log_{10}(I_0/I)=\varepsilon lc\)。输入是浓度 \(c\)，输出是吸光度 \(A\)。
  • 读法：\(I_0\) 是入射光，\(I\) 是透射光；吸收越强，\(I\) 越小，\(A\) 越大。
  • 考点：固定波长和光程时，\(\varepsilon l\) 就是校准斜率。超出线性范围、浑浊散射或仪器杂散光会让这个关系失效。

图 4-1：动态响应由暂态进入稳态

  • 图里：输入突然变化后，输出 \(c(t)\) 不是立刻到稳态，而是先经历 transient state，再接近 steady state。
  • 读法：曲线越快贴近虚线稳态值，响应越快；若存在振荡，还要看超调和稳定时间。
  • 考点：稳态准确不代表动态快。温度计、压力传感器、酶传感器都可能有响应滞后。

图 4-2：响应可以分成暂态项和稳态项

  • 图里：\(c(t)=c_{tr}(t)+c_{ss}(t)\)，其中 \(c_{tr}(t)\) 是暂态响应，\(c_{ss}(t)\) 是稳态响应。
  • 读法：暂态项通常随时间衰减；稳态项决定最终读数。动态分析主要关心暂态项消失得多快。
  • 考点：若题目问 settling time 或 response time，它问的是暂态何时足够小，而不是最终值是多少。

图 5-1：校准曲线把物理输入变成信号输出

  • 图里：横轴是 physical input \(X\)，纵轴是 signal output \(Y\)。点是标准样本，直线是拟合出的校准关系。
  • 读法：斜率代表灵敏度，截距代表零点偏置或背景信号。
  • 考点：未知样本只能在校准范围内插值。若未知点落在最高标准点之外，严格来说是外推，可信度下降。

图 5-2：精密度和准确度是两件事

  • 图里：左侧点群很集中但偏离靶心，说明 precision 高、accuracy 低；右侧点分散但均值接近靶心，说明 accuracy 可以还行但 precision 差。
  • 读法：precision 看重复测量的散布，accuracy 看均值离真值的距离。
  • 考点：系统误差影响 accuracy，随机噪声影响 precision；校准主要修正系统误差，重复测量和降噪主要改善 precision。

图 5-3：LOD 是“看得见”，LOQ 是“量得准”

  • 图里：绿色线是 baseline，蓝色波动是 noise。Peak A 只达到 LOD，Peak B 达到 LOQ。
  • 读法：LOD 要求峰超过噪声到可辨认；LOQ 要求峰足够高，可以给可靠数值。
  • 考点：降低噪声、提高校准斜率都能降低 LOD/LOQ。不要把低于 LOQ 的信号报告成精确浓度。

图 5-4：灵敏度和特异性的分母不同

  • 图里：四格表把真实疾病状态和测试结果交叉：TP、FP、FN、TN。
  • 读法：sensitivity 看“有病的人里检出多少”：\(TP/(TP+FN)\)；specificity 看“没病的人里排除多少”：\(TN/(TN+FP)\)。
  • 考点：假阴性 FN 会伤害 sensitivity，假阳性 FP 会伤害 specificity。筛查通常重视 sensitivity，确诊通常更重视 specificity。

图 5-5：斜率是灵敏度，平台是饱和

  • 图里：信号随浓度增加先上升，随后逐渐变平。箭头标出 LOL，limit of linearity。
  • 读法：初始斜率越大，低浓度区越敏感；平台区说明识别位点、反应速率或读出电路接近饱和。
  • 考点：线性校准只能用于线性范围。饱和区里再增加浓度，信号变化很小，定量误差会很大。

图 6-1：水银温度计的灵敏度和响应速度相互牵制

  • 图里：灵敏度 \(k=K_{ex}V_b/A_c\)，时间常数 \(\tau=\rho C V_b/(UA_b)\)。
  • 读法：\(V_b\) 增大能让温度变化产生更大的液柱位移，但也增大热容量，使响应变慢。
  • 考点：设计题不能只追求灵敏度。高灵敏度可能带来更大 \(\tau\)，需要通过增大接触面积 \(A_b\) 等方式补偿。

图 6-2：几何量决定温度计读数和动态

  • 图里：球泡与液柱相连，温度从 \(T_i(t)\) 变化到最终 \(T_f\)，液柱位移用 \(x_o\) 表示。
  • 读法：细管横截面积 \(A_c\) 越小，同样体积膨胀产生的位移越大；球泡与环境接触面积影响换热速度。
  • 考点：这是典型一阶系统。若题目给阶跃温度变化，输出不会瞬间到达最终读数。

图 7-1：二阶系统用曲线读出四个时间域指标

  • 图里：输出从 0 上升，超过稳态值产生 overshoot \(\alpha\)，随后振荡衰减并进入 \(\pm\Delta\%\) 误差带。
  • 读法：rise time \(t_r\) 是从 10% 到 90%；response/settling time \(t_s\) 是进入误差带并保持稳定；\(\alpha_1\) 是下一个峰的超调。
  • 考点：快不一定好。很短 rise time 如果伴随大 overshoot，在医疗传感或控制里可能不可接受。

图 8-1：Biomarker 不只等于“血液里的分子”

  • 图里：生物标志物是可测量特征，用于指示正常生物过程、病理过程或治疗响应。
  • 读法：类型包括 molecular、histologic、radiographic、physiologic；例子包括血糖、肿瘤大小、血压。
  • 考点：传感器课程里的 biomarker 可以是分子浓度，也可以是生理量或影像量。不要把 biomarker 狭义理解成蛋白或核酸。

图 9-1：单分子在细菌体积里就是 nM 量级

  • 图里：细菌体积约 \(1\ \mu m^3=1\ fL\)，一个分子除以 \(1\ fL\) 后换算成摩尔浓度约 \(1.6\ nM\)。
  • 读法：这是数量级直觉，不是精确生物学常数。不同细胞体积会改变结果。
  • 考点：看到 LOD 时要能判断是否够用。若目标是单细胞稀有分子，\(\mu M\) 或 100 nM 检测限往往不够。

图 10-1：酶识别不是硬钥匙模型，而是诱导契合

  • 图里：底物进入 active site 后，酶构象略变，形成 enzyme-substrate complex，再生成产物并释放。
  • 读法：传感器利用的是酶对底物的选择性和催化放大能力。
  • 考点：温度、pH、抑制剂、底物类似物都会影响酶构象和活性，因此会影响传感信号。

图 10-2：Michaelis-Menten 解释“低浓度线性、高浓度饱和”

  • 图里：\(v_0=V_{\max}[S]/(K_M+[S])\)，底物浓度进入分子和分母。
  • 读法：\([S]\ll K_M\) 时 \(v_0\) 近似正比于 \([S]\)；\([S]\gg K_M\) 时 \(v_0\) 接近 \(V_{\max}\)。
  • 考点：酶传感器的定量最好放在线性或可校准区间。高浓度饱和会降低区分能力。

图 11-1：两条葡萄糖酶反应路线

  • 图里：GOx 路线消耗 \(O_2\)，生成 gluconolactone 和 \(H_2O_2\)；GDH 路线使用 \(NAD^+\)，生成 NADH。
  • 读法：这两条路线都把葡萄糖变成可读出的化学变化，但读出对象不同。
  • 考点：GOx 第一代传感器常通过 \(H_2O_2\) 电氧化读电流；GDH 系统可能使用辅因子或介体传递电子。

图 11-2：第一代葡萄糖传感器的信号来自 \(H_2O_2\)

  • 图里：葡萄糖经 GOx 反应生成 gluconolactone，同时 \(O_2/H_2O_2\) 参与氧化还原，最后电子进入电极。
  • 读法：电极并不“直接看见葡萄糖”，而是看见酶反应产物 \(H_2O_2\) 的电化学氧化。
  • 考点：依赖氧气、工作电位较高、可能被抗坏血酸/尿酸等干扰，这是第一代方案的经典问题。

图 12-1：安培型传感器用电极反应产生电流

  • 图里：Ag/AgCl 参考电极、Pt 工作电极和外加 350 mV 构成电化学测量环境；葡萄糖和氧进入酶层，产物 \(H_2O_2\) 到达 Pt。
  • 读法：参考电极稳定电位，工作电极发生目标氧化还原反应，电流由电子转移形成。
  • 考点：amperometric 的定义是测电流，不是测电压。电位只是为了驱动特定电极反应。

图 12-2：把总反应拆成酶反应和电极反应

  • 图里：第一步是 GOx 催化葡萄糖生成葡萄糖酸和 \(H_2O_2\)；第二步是 \(H_2O_2\) 在 Pt 阳极氧化；后面是参考/辅助电极反应。
  • 读法：不要把所有反应混成一个黑箱。传感选择性来自酶，电信号来自电极反应。
  • 考点：若电极反应受限或扩散受限，电流不再只由葡萄糖浓度决定。

图 13-1：不同波段激发不同类型的物质响应

  • 图里：频率从 gamma ray 到 radio wave 递减，波长递增；可见光只是很窄一段。
  • 读法：UV/visible 主要关联电子跃迁，IR 关联分子振动，microwave 关联转动或电子自旋，radio wave 关联核自旋。
  • 考点：选择光谱方法时要先问目标物会在哪个能量尺度上响应，而不是所有分子都用同一种光。

图 13-2：比色皿里的 \(l\) 是光程，不是液体高度

  • 图里：光从左到右穿过 cuvette，箭头下方的 \(l\) 是光穿过样品的距离。
  • 读法：吸光度与 \(l\) 和 \(c\) 都成正比，所以不同光程的比色皿不能直接比较吸光度。
  • 考点：题目给 0.5 cm 或 1 cm 光程时，必须代入。不要默认所有 cuvette 都是 1 cm。

图 13-3：UV-vis 的核心是选波长再测透过光

  • 图里：光源发出宽谱光，经过入口狭缝、色散元件和出口狭缝选出窄波长，再穿过样品到 detector。
  • 读法：monochromator 的作用是让检测只发生在指定波长，避免不同波长混在一起。
  • 考点：吸收峰最大处通常灵敏度高；但若样品基质也吸收同一波长，会产生干扰。

图 13-4：荧光读的是发射光，不是透过光

  • 图里：蓝色是 absorption，绿色是 fluorescence，红色是 phosphorescence。发射峰通常比吸收峰波长更长。
  • 读法：荧光传感常用“是否发光、发光增强/淬灭、峰位变化”来报告目标存在。
  • 考点：荧光很灵敏，但会受光漂白、自发荧光、内滤效应和探针环境影响。

图 13-5：FTIR 看的是分子振动方式

  • 图里：stretch 是键长方向的伸缩，bending 是键角改变的弯曲。
  • 读法：不同化学键和官能团有特征振动频率，因此 FTIR 常用于识别化学组成。
  • 考点：FTIR 不像 UV-vis 那样主要问电子吸收，而是问分子振动；水和复杂基质的吸收可能干扰。

图 14-1：NIR 窗口来自血红蛋白和水吸收的夹缝

  • 图里：可见光区血红蛋白吸收强；650 nm 后血红蛋白吸收下降；950 nm 后水吸收开始显著增强。
  • 读法：NIR-I 大致在 650-950 nm，NIR-II 在更长波段。PPT 强调 650-950 nm 是吸收较低的组织窗口。
  • 考点：近红外能进组织更深，不是因为“能量更高”，而是因为主要吸收体在这个窗口吸收较低。

图 14-2：波长越长，组织穿透通常越深

  • 图里：550、630、700、800 nm 的相对穿透深度逐步增加。
  • 读法：长波长散射更弱，且在 NIR 窗口吸收低，所以更容易穿透组织。
  • 考点：穿透深不等于分辨率一定好。长波长通常衍射极限更大，成像分辨率可能降低。

图 15-1：抗体检测的核心量是结合与解离

  • 图里：抗体结构旁边给出 \(A+B\rightleftharpoons AB\)，结合速率 \(k_{on}[A][B]\)，解离速率 \(k_{off}[AB]\)。
  • 读法：平衡时二者相等，得到 \(K_D=[A][B]/[AB]=k_{off}/k_{on}\)。
  • 考点：\(K_D\) 越小，亲和力越强。传感器不仅要有强结合，还要有低非特异吸附和合适的解离动力学。

图 15-2：SPR 用折射率变化读出表面结合

1. 传递函数与校准：传感器到底在“翻译”什么

传感器不是直接给你“真实世界答案”，它先给出一个信号。传递函数描述真实刺激 \(X\) 与输出信号 \(S\) 的关系，校准则是用已知标准样本把这个关系估出来。

1.1 从被测量到显示值

典型链路是：measurand 产生 physical measurement variable \(X\)，传感器输出 signal variable \(S\)，显示或算法给出 measurement \(M\)。考试时如果让你“说明传感器工作过程”，不要只说材料名，要按这条链路说明输入、换能机制、输出和校准。

\[X \xrightarrow{\text{sensor}} S \xrightarrow{\text{calibration/display}} M\]

1.2 为什么不是所有响应都线性

线性响应 \(S=a+bX\) 最容易用，因为斜率就是灵敏度。但很多传感器受反应动力学、扩散、吸附位点饱和、电子学放大范围限制，会出现对数、指数、多项式或饱和响应。看到非线性响应时，先问：能否在小范围内线性近似？是否需要取对数或用标准曲线插值？

法
校准题模板：先写 \(S=f(X)\)，说明 \(X\) 和 \(S\) 的单位；再用标准点拟合参数；最后把未知样品的 \(S\) 代回求 \(X\)。如果样品超出校准范围，不能外推当作可靠结果。

例题 1：Beer-Lambert Law 作为传递函数

定量

题目：某物质在固定波长下 \(\varepsilon=2.0\times10^4\ \mathrm{L\,mol^{-1}\,cm^{-1}}\)，比色皿光程 \(l=1.0\ \mathrm{cm}\)。测得 \(I_0/I=10\)。求浓度。

  1. 先把信号写成吸光度：\(A=\log_{10}(I_0/I)=\log_{10}10=1\)。
  2. 把 Beer-Lambert Law 看作传递函数：\(A=\varepsilon l c\)。
  3. 代入：\(c=A/(\varepsilon l)=1/(2.0\times10^4\times1.0)=5.0\times10^{-5}\ \mathrm{M}\)。

解释：这里输入 \(X\) 是浓度 \(c\)，输出 \(S\) 是吸光度 \(A\)。斜率 \(\varepsilon l\) 越大，同样浓度变化引起的吸光度变化越大，灵敏度越高。

2. 传感器特性：如何判断一个测量“好不好”

传感器特性分静态和动态。静态特性回答“稳态值准不准、噪声大不大、能测多低、多宽”；动态特性回答“输入改变后多久跟上、是否超调、是否振荡”。

2.1 静态指标总表

指标一句话定义直觉常见错误
Accuracy测量均值接近真值的程度。靶心图中点群中心离靶心近。把 accuracy 与 precision 混用。
Precision重复测量彼此接近的程度。点群聚得紧。精密但不准确是可能的。
Sensitivity输出随输入变化的斜率。校准曲线越陡，单位输入变化越容易被看到。把 sensitivity 与 specificity 混淆。
Specificity识别目标而不响应非目标的能力。健康者被判阴性的比例高。只看阳性样本，不看假阳性。
Linearity输出与输入是否近似直线关系。线性范围内可用一个斜率描述。把饱和区也拿来线性拟合。
Hysteresis输入上升和下降路径得到不同输出。加载/卸载曲线不重合。只做单方向校准。
LOD能可靠“看见”的最低量。信号刚超过噪声。把 LOD 当成可准确定量的最低点。
LOQ能可靠“定量”的最低量。通常高于 LOD。报告低于 LOQ 的精确数值。
SNR信号相对噪声强度。越大越容易识别真实峰。只看峰高，不看基线噪声。
Repeatability同条件重复结果一致性。同人同仪器同环境。与 reproducibility 混用。
Reproducibility不同条件下结果一致性。不同人、不同仪器、不同实验室。只在一个实验室验证就说可复现。

2.2 灵敏度与特异性：用混淆矩阵别混

\[ \text{sensitivity}=\frac{TP}{TP+FN},\quad \text{specificity}=\frac{TN}{TN+FP},\quad \text{PPV}=\frac{TP}{TP+FP},\quad \text{NPV}=\frac{TN}{TN+FN} \]

PPT 中列出 TP、FP、FN、TN。重点是分母不同：sensitivity 的分母是所有真正有病者，specificity 的分母是所有真正无病者。阳性预测值 PPV 和阴性预测值 NPV 虽不在 PPT 主图中，但常和前两者一起出现，受患病率影响很大。

例题 2：从混淆矩阵计算指标

诊断统计

题目：100 名患病者中检测阳性 92 人，100 名无病者中检测阳性 8 人。求 sensitivity 和 specificity。

  1. 患病且阳性：\(TP=92\)。患病但阴性：\(FN=8\)。
  2. 无病但阳性：\(FP=8\)。无病且阴性：\(TN=92\)。
  3. \(\text{sensitivity}=92/(92+8)=92\%\)。
  4. \(\text{specificity}=92/(92+8)=92\%\)。

易错点：如果题目把总人数、患病人数、阳性人数混在一起给，先画四格表再算，不要直接拿阳性总数当分母。

2.3 噪声、LOD、LOQ 与 SNR

LOD 和 LOQ 的核心不是“有没有信号”，而是信号相对噪声是否足够可靠。PPT 图中 Peak A 到达 LOD，只能说明存在可检出信号；Peak B 到达 LOQ，才适合给出可信浓度数值。常见经验是 LOD 约为空白均值加 3 倍噪声标准差，LOQ 约为空白均值加 10 倍噪声标准差；若把信号换成浓度，则除以校准曲线斜率。

例题 3：用噪声和斜率估算 LOD/LOQ

常用补充

题目：空白噪声标准差 \(\sigma_b=0.015\ \mathrm{A.U.}\)，校准曲线斜率 \(m=0.30\ \mathrm{A.U./nM}\)。估计 LOD 和 LOQ。

  1. \(LOD\approx 3\sigma_b/m=3\times0.015/0.30=0.15\ \mathrm{nM}\)。
  2. \(LOQ\approx 10\sigma_b/m=10\times0.015/0.30=0.50\ \mathrm{nM}\)。

解释：增大斜率或降低噪声都会降低 LOD/LOQ。单纯放大信号如果同时放大噪声，不一定改善 LOD。

2.4 动态特性：一阶系统与二阶系统

一阶系统：水银温度计

PPT 用水银温度计说明 sensitivity \(k\) 与 time constant \(\tau\) 的权衡。更大的 bulb volume \(V_b\) 提高位移灵敏度，但也让系统热容量变大，响应变慢；更大的接触面积 \(A_b\) 和换热系数 \(U\) 有助于降低 \(\tau\)。

\[k=\frac{K_{ex}V_b}{A_c},\qquad \tau=\frac{\rho C V_b}{UA_b}\]

二阶系统：阶跃响应

二阶响应常见振荡。rise time 是从 10% 到 90% 的时间；response time 或 settling time 是进入并保持在误差带内的时间；overshoot 是最大峰值超过稳态值的量；attenuation 描述相邻峰值衰减。

\[\psi=\frac{\alpha-\alpha_1}{\alpha}\times100\%\]
辨
静态 vs 动态：如果题目问“稳态时读数是否接近真实值”，这是静态准确性；如果题目问“突然输入后多久到达稳定读数”，这是动态响应。一个传感器可以稳态很准但响应很慢。

3. 生物标志物与浓度直觉

生物标志物是能被测量、并指示正常生物过程、病理过程或治疗响应的特征。传感课程关心的不只是“能不能检测”，还要知道标志物在哪个尺度、什么浓度、是否有干扰。

Molecular

分子标志物，如血糖、蛋白、核酸、代谢物。传感器常直接识别分子结构或反应产物。

Histologic / Radiographic

组织学或影像学标志物，如肿瘤组织形态、肿瘤大小。它们常通过图像或病理流程获得。

Physiologic

生理标志物，如血压、心率、体温。常与压力、位移、光学或电生理传感器相关。

3.1 一个分子在细菌体积里是什么浓度

PPT 用这个问题建立数量级直觉：细菌体积约 \(1\ \mu m^3=1\ fL=10^{-15}\ L\)。如果一个这样的体积里只有 1 个分子，摩尔浓度为：

\[ c=\frac{1\ \text{molecule}}{1\ fL}\times \frac{1\ \text{mol}}{6\times10^{23}\ \text{molecules}}\times \frac{1\ fL}{10^{-15}\ L} \approx 1.6\times10^{-9}\ M=1.6\ nM \]

因此经验规则是：一个细菌体积中的一个分子约等于 nM 量级。这能帮助你判断检测限是否足够。例如某传感器 LOD 为 100 nM，它对单细胞内单分子事件通常不够敏感；如果 LOD 到 pM 或 fM，才有机会观察稀有分子。

4. 酶传感与电化学：从血糖检测到安培型传感器

酶传感的基本想法是：酶把目标底物转成产物，产物或反应过程引起可测电信号。血糖传感器是最经典例子。

4.1 Michaelis-Menten 方程的物理含义

\[v_0=\frac{V_{\max}[S]}{K_M+[S]}\]

\(v_0\) 是初始反应速率，\([S]\) 是底物浓度，\(V_{\max}\) 是酶位点全部被充分利用时的最大速率，\(K_M\) 是速率达到 \(V_{\max}/2\) 时的底物浓度。它告诉你：低浓度时速率随浓度近似线性，高浓度时酶位点接近饱和，继续增加浓度也不能显著增加速率。

浓度范围近似传感意义
\([S]\ll K_M\)\(v_0\approx (V_{\max}/K_M)[S]\)适合定量，响应近似线性。
\([S]=K_M\)\(v_0=V_{\max}/2\)\(K_M\) 可视为酶对底物亲和/工作范围的尺度。
\([S]\gg K_M\)\(v_0\approx V_{\max}\)系统饱和，高浓度区分能力下降。

4.2 三类电化学读出

Potentiometric

测电压。典型问题是某种离子活度改变电极电位，例如 pH 电极、离子选择电极。

Amperometric

测电流。目标反应在电极上氧化还原，电流与反应速率和物质通量相关。葡萄糖传感器重点属于这一类。

Conductometric

测电导。反应改变溶液中离子浓度或迁移能力，从而改变电导。

4.3 第一代葡萄糖生物传感器

PPT 中给出的核心反应链是：

\[ \text{glucose}+O_2 \xrightarrow{GO_x} \text{gluconolactone}+H_2O_2 \]

生成的 \(H_2O_2\) 在 Pt 工作电极上被氧化：

\[ H_2O_2 \xrightarrow{\text{Pt anode}} O_2+2H^+ +2e^- \]

电极收集电子形成电流，电流大小与 \(H_2O_2\) 产生速率相关，也就与葡萄糖浓度相关。第一代传感器的弱点也来自这里：它依赖氧气，并且高电位氧化 \(H_2O_2\) 时可能受到其他可氧化物质干扰。

例题 4：判断葡萄糖传感器的输入、转导和输出

答题模板

题目：简述第一代 GOx 葡萄糖传感器如何测量血糖。

  1. 识别层：葡萄糖氧化酶 GOx 对葡萄糖有选择性，催化葡萄糖与 \(O_2\) 反应。
  2. 化学转化：葡萄糖被氧化生成 gluconolactone，同时产生 \(H_2O_2\)。
  3. 电化学转导：\(H_2O_2\) 在 Pt 电极上氧化产生电子，形成可测电流。
  4. 校准定量：用已知葡萄糖浓度建立电流-浓度曲线，再由未知样品电流反推浓度。
  5. 限制：氧气供应、酶活性、扩散、干扰物和电极污染都会影响结果。

5. 分子光谱与近红外荧光

光谱传感的共同思想是：分子和光相互作用会改变光的强度、波长、相位或时间特性。不同光谱方法对应不同能级或分子运动。

方法主要测什么典型输出适合回答的问题

5.1 Beer-Lambert Law 的使用边界

Beer-Lambert Law 把浓度与吸光度联系起来，但它不是无限适用。高浓度时分子间相互作用、散射、杂散光、仪器动态范围都可能破坏线性。因此定量时必须有标准曲线，并说明样品落在线性范围内。

错
常见错误：把 \(I\) 和 \(I_0\) 颠倒。吸光度定义为 \(A=\log_{10}(I_0/I)\)。样品吸收越强，透过光 \(I\) 越小，\(A\) 越大。

5.2 为什么 650-950 nm 是组织光学窗口

PPT 的关键结论是：可见光尤其短波段被 hemoglobin 强吸收；当波长超过 650 nm，血红蛋白吸收显著降低；但超过 950 nm 后，水吸收明显增加。因此 650-950 nm 之间吸收较小，光能在组织中传播更深，适合近红外荧光成像和体内检测。

波段主要限制传感意义
< 650 nm血红蛋白吸收强，散射也明显。穿透浅，更适合表面或透明样品。
650-950 nm吸收相对较低。组织光学窗口，适合深部荧光检测。
> 950 nm水吸收增强。穿透受到水吸收限制，热效应需考虑。

6. 免疫检测、ELISA 与纳米材料

抗体传感的核心是分子识别：抗体与抗原特异结合，结合事件通过光、电、质量、折射率或颜色变化读出。

6.1 抗体结合与 \(K_D\)

把抗体和抗原分别记为 \(A\) 和 \(B\)，复合物为 \(AB\)。结合速率与 \([A][B]\) 成正比，解离速率与 \([AB]\) 成正比。平衡时：

\[ k_{on}[A][B]=k_{off}[AB],\qquad K_D=\frac{[A][B]}{[AB]}=\frac{k_{off}}{k_{on}} \]

\(K_D\) 越小，说明在较低浓度下也能形成较多复合物，亲和力更高。考试中如果问“哪个抗体更好”，不能只看是否结合，还要看 \(K_D\)、交叉反应、稳定性和检测背景。

6.2 SPR 与 QCM-D

SPR

Surface plasmon resonance 通过表面折射率变化检测结合事件。抗原抗体结合改变金膜附近折射率，使共振角或响应信号变化。优点是可实时、无标记监测结合和解离。

QCM-D

Quartz crystal microbalance with dissipation 通过石英晶体频率变化和耗散变化反映表面质量加载与层的黏弹性。频率下降通常意味着表面吸附质量增加；耗散变化帮助判断层是刚性还是软/含水。

6.3 ELISA 五种类型

类型基本流程适合对象结果解释
Direct ELISA抗原固定，酶标一抗直接结合。流程短、目标明确。颜色越深通常目标越多。
Indirect ELISA抗原固定，一抗结合，再加酶标二抗。检测抗体或提高信号。二抗提供放大，但增加非特异风险。
Sandwich ELISA捕获抗体固定，夹住抗原，再用检测抗体读出。蛋白、抗原定量，特异性高。需要抗原有两个可被识别的表位。
Competitive ELISA样品目标与标记目标竞争结合位点。小分子或单表位目标。样品越多，常见读出信号反而越低。
Multiplex ELISA同时检测多个目标。细胞因子、多标志物面板。需要防止交叉反应和信号串扰。

6.4 Lateral flow assay：为什么一条线阳性、一条线有效

侧向层析试纸由 sample pad、conjugate pad、nitrocellulose membrane、wicking pad 等组成。样品沿毛细作用流动，带着标记抗体或纳米颗粒移动。test line 上固定的识别分子捕获目标复合物，显示阳性；control line 捕获流过的标记物，证明液体流动和试剂有效。若 control line 不出现，无论 test line 如何，都应判为无效。

7. 核酸检测：Aptamer、PCR 与 Covid-19 检测策略

核酸检测把“序列互补”和“扩增”作为核心放大机制。PPT 同时把 aptamer 放在这里，因为 aptamer 本身是可折叠的核酸识别分子，能像抗体一样结合目标。

Aptamer

Aptamer 是筛选得到的短 DNA/RNA 序列。它不是靠 Watson-Crick 配对识别另一条核酸，而是折叠成三维结构后与蛋白、小分子或细胞表面目标结合。优点是可化学合成、易修饰、批间差异小；限制是结构受离子强度、温度和样品基质影响。

PCR probe

TaqMan 探针使用双标记荧光水解探针，扩增时探针被聚合酶水解，荧光与淬灭基团分离，信号上升。FRET 杂交探针依赖供体和受体距离变化。共同点是把序列特异性转换成荧光信号。

8. 物理传感器与 MEMS：把力、位移、压力、磁场转成电信号

物理传感器部分的学习重点是“输入变量改变了哪个电学量”。只要能说清电阻、电容、电感、电压、频率或相位如何随输入变化，就抓住了主线。

8.1 电阻式：电位器、应变片与 Wheatstone bridge

电位器位移传感器

滑动触点位置改变有效电阻，输出电压按分压关系变化。优点是直观、成本低；缺点是机械接触带来磨损、摩擦和寿命问题。

应变片

拉伸使导体长度增加、截面积减小，电阻通常增大；压缩时电阻减小。应变片对轴向应变敏感，对横向力可能不敏感，因此安装方向很关键。

Wheatstone bridge 用于把很小的电阻变化变成差分电压：

\[ V_{TH}=V\left(\frac{R_1}{R_1+R_3}-\frac{R_2}{R_2+R_4}\right) \]

桥路平衡时输出为零；某一臂电阻因应变变化，桥路失衡，输出电压就能反映应变大小。

8.2 电容式与电感式

电容传感

\[C\approx \varepsilon_0\varepsilon_r\frac{ab}{d}\]

压力可改变板间距 \(d\)，液位可改变介电常数 \(\varepsilon_r\)，触摸可引入手指电容，人体穿戴传感可利用身体与电极间耦合电容。

电感传感

线圈电流变化产生磁场，磁场变化又产生感应电压。位移、金属接近、磁芯位置变化都可改变电感或耦合。它适合非接触测量，但对电磁干扰和环境金属敏感。

8.3 压电传感器

压电材料在机械应力下产生电荷/电压；反过来，施加电场也会让材料形变，这叫逆压电效应。PPT 中举例包括 quartz crystals、sucrose、DNA、silk、tendon。压电压力传感器特别适合动态、快速或微小压力变化，因为变化越快越容易产生明显电荷输出；但纯静态长期压力测量会受到电荷泄漏和漂移限制。

答
压电题答法：先说“机械应力导致极化/电荷分离”，再说“电极收集电荷形成电压”，最后指出适合动态压力、振动和脉动测量。

8.4 光纤、Hall 与 MEMS

类型输入改变什么输出读什么典型优点
Intensity-modulated fiber弯曲、压力或吸收改变光强。输出光强。结构简单，远距离传输。
Wavelength-modulated fiber应变/温度改变光栅周期或折射率。反射/透射波长。抗强度波动，适合多点复用。

10. 综合题库：按答案思路训练

下面的题不追求覆盖所有细枝末节，而是训练 PPT 最可能考的概念链路。建议先自己回答，再展开参考答案。

题 1：什么是 transfer function？为什么校准曲线很重要？
Transfer function 描述输入刺激 \(X\) 与输出信号 \(S\) 的关系，即 \(S=f(X)\)。校准曲线用已知标准样品确定 \(f\) 的形式和参数，使未知样品的信号可以反推浓度、压力或其他被测量。没有校准，信号只是电流、电压或光强，不能直接等同真实量。
题 2：accuracy 和 precision 的区别是什么？
Accuracy 关注测量均值离真值多近；precision 关注重复测量彼此多接近。一个系统可以 precision 高但 accuracy 低，例如所有点都聚在一起但偏离靶心；也可以 accuracy 较好但 precision 低，例如点分散但均值接近真值。
题 3：LOD 和 LOQ 有什么区别？
LOD 是最低可检出量，说明信号能从噪声中被看见；LOQ 是最低可定量量，说明信号足够高，可以给出可信数值。LOQ 通常高于 LOD。报告低于 LOQ 的精确定量值是不严谨的。
题 4：为什么水银温度计的灵敏度和响应速度存在权衡？
更大的 bulb volume \(V_b\) 会让温度变化引起更大的液柱位移，因此提高灵敏度；但它也增加热容量，使时间常数 \(\tau=\rho C V_b/(UA_b)\) 增大，响应变慢。增大接触面积 \(A_b\) 或换热系数 \(U\) 可以缩短时间常数。
题 5：Michaelis-Menten 方程中 \(K_M\) 的意义是什么？
\(K_M\) 是反应速率达到 \(V_{\max}/2\) 时的底物浓度。它给出酶传感器从线性区走向饱和区的浓度尺度。低于 \(K_M\) 很多时，速率近似与浓度成正比；高于 \(K_M\) 很多时，速率接近 \(V_{\max}\)。
题 6：第一代葡萄糖传感器为什么属于 amperometric sensor？
因为它最终测量的是电极上的氧化还原电流。GOx 催化葡萄糖生成 \(H_2O_2\)，\(H_2O_2\) 在 Pt 电极上氧化产生电子，电流与反应速率相关。通过校准可由电流反推葡萄糖浓度。
题 7：为什么近红外 650-950 nm 适合组织检测？
在 650 nm 以下，血红蛋白吸收较强；在 950 nm 以上，水吸收明显增强。650-950 nm 区间吸收相对较低，光可以在组织中传播更深，因此称为组织光学窗口。
题 8：\(K_D\) 越大越好吗？
不是。\(K_D=[A][B]/[AB]=k_{off}/k_{on}\)，数值越小表示较低浓度下也能形成较多复合物，亲和力越强。高 \(K_D\) 通常意味着结合弱或容易解离。
题 9：sandwich ELISA 为什么通常特异性高？
因为目标抗原需要同时被捕获抗体和检测抗体识别，相当于双重识别。但它要求抗原有至少两个可同时识别的表位，因此小分子或单表位目标不一定适合。
题 10：侧向层析试纸的 control line 有什么作用？
control line 证明样品流动、标记试剂释放和反应体系基本有效。若 control line 不出现，即使 test line 出现，也应判为无效测试。
题 11：RNA 检测、抗原检测、抗体检测分别说明什么？
RNA 检测说明样品中存在病毒遗传物质；抗原检测说明存在病毒蛋白或较完整病毒颗粒；抗体检测说明宿主产生过免疫反应，不能直接等同当前感染。
题 12：电容式压力传感器中压力增大导致间距变小，电容如何变化？
由 \(C=\varepsilon A/d\)，若 \(A\) 和 \(\varepsilon\) 不变，\(d\) 减小会使 \(C\) 增大。
题 13：压电传感器为什么适合动态压力或振动？
压电材料在应力变化时产生电荷/电压，动态载荷会持续产生可测信号；静态载荷下电荷可能泄漏，读数易漂移，因此压电传感器尤其适合快速变化、脉动和振动测量。
题 14：Hall sensor 的输入和输出分别是什么？
输入是垂直于电流方向的磁场，输出是横向 Hall voltage。磁场使载流子受洛伦兹力偏转，在横向形成电势差。
题 15：MEMS 的三类主要 transducers 是什么？
PPT 列出三类主要 transducers：capacitive、piezoelectric、thermal；另外还可包括 microfluidic。MEMS 常把微结构、传感器和执行器集成在微尺度芯片上。
